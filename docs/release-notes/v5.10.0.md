## Synxio Player 5.10.0 — Au poignet

### Nouveautés
- **Synxio sur ta montre Wear OS** : ce qui joue, lecture/pause, précédent/suivant, le cœur,
  et le volume à la couronne. Depuis « Lancer » : Reprendre, Favoris, Aléatoire,
  Surprends-moi, sans toucher le téléphone.
- **Tuile « en cours »** : titre, artiste, lecture/pause · suivant · cœur, à un balayage du
  cadran. Sans lecture, Reprendre et Favoris.
- **Complication « en cours »** : le titre ou la pochette sur ton cadran, un appui ouvre
  Synxio.
- **Mode ambiant** : lecteur à plat, sans fond ni boutons, pour l'écran toujours allumé.

### Sous le capot
- Nouveau module `:wear` (Compose for Wear OS Material 3, Tiles, Complications) et module
  `:wear-protocol` partagé. Le téléphone publie son état sur le Wearable Data Layer à chaque
  transition ; la montre extrapole la position, rien ne tourne en continu.
- Version commune téléphone/montre dans `gradle.properties`. La release GitHub publie
  désormais deux APK.

### Installation
Voir le README, section « Montre (Wear OS) » : l'APK montre se pousse par ADB Wi-Fi.
