## Synxio Player 5.5.0 — Notes, tuile et vitesse par podcast

### Nouveautés
- **Notes de 1 à 5 étoiles** : sous le titre dans le lecteur et dans l'éditeur de tags.
  Toucher la note déjà donnée l'efface. Nouvelle règle « Note (étoiles) » dans les
  playlists à règles (par exemple « note supérieure à 3 »). Les notes sont incluses dans
  la sauvegarde.
- **Tuile des Réglages rapides** : lecture / pause depuis le volet de notifications, avec le
  titre en cours. Appui long : ouvre Synxio. À ajouter depuis l'édition des tuiles.
- **Enregistrer la file d'attente en playlist** : bouton « Enregistrer » dans la file.
- **Vitesse par podcast et par livre audio** : la vitesse choisie est retenue pour chaque
  émission ; la musique garde la sienne.

### Sécurité
- Préparation du changement de clé de signature : cette version accepte les mises à jour
  signées par la future clé (rotation transparente, sans réinstallation ni perte de données).
