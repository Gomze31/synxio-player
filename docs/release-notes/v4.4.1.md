## Synxio Player 4.4.1 — correctif

### Corrigé
- **Les titres défilaient sans s'arrêter sans rien jouer.** Quand un titre ne pouvait pas être lu, Synxio passait au suivant ; si tous échouaient, la file défilait indéfiniment. Désormais Synxio s'arrête après 3 échecs d'affilée, et n'enchaîne que tant que la lecture fonctionne vraiment (10 s d'écoute).
- Un message s'affiche quand un titre est illisible, avec le code d'erreur (par exemple `ERROR_CODE_DECODING_FAILED`). **Si tu le vois, envoie-le : il indique la cause exacte.**
- Mode karaoké : retour au fonctionnement éprouvé de la 4.3.0 (il s'applique au titre suivant).
