## Synxio Player 5.3.0 — Montée de version majeure de l'outillage

Aucune fonction nouvelle : cette version remet toute la chaîne de construction et toutes les bibliothèques au dernier niveau stable, et cible Android 17.

### Plateforme
- Cible Android 17 (`targetSdk 37`, compilation contre l'API 37.2). Compatibilité inchangée depuis Android 8.0.
- Android Gradle Plugin 9.4.1 et Gradle 9.8.2, avec le Kotlin intégré à AGP (le plugin `kotlin-android` disparaît).
- Kotlin 2.4.21, KSP 2.3.12, Hilt 2.60.1.

### Bibliothèques
- Jetpack Compose (BOM 2026.09), Material 3, Lifecycle 2.11, Activity 1.13, Navigation 2.10, DataStore 1.3, Glance 1.2, Palette 1.1, Core 1.19.
- Media3 1.11.1 (ExoPlayer, session, Cast) et services Cast 23.
- Room 2.8.5.
- Coil 3 pour les pochettes (nouveau moteur d'images), OkHttp 5, kotlinx.serialization 1.12.

### Sous le capot
- API de session Media3 modernisées (acceptation des connexions, reprise de lecture).
- Dépréciations Compose résolues (éléments partagés, menus déroulants).
- Script de build prêt pour Gradle 10 (plus d'appel à `project.properties`).

### Vérification
- Tests unitaires, lint et build release passés ; parcours complet vérifié sur un appareil Android 17.
