## Synxio Player 5.17.0 — Mode Flow (6.0, étape 7)

Septième étape de la 6.0 « Flow » (`docs/superpowers/specs/2026-11-24-synxio-6.0-flow-design.md`, §7 ; plan `docs/superpowers/plans/2026-11-25-synxio-6.0-etape-7-flow.md`).

### Nouveautés
- **Flow dans la file d'attente** : dans la feuille « File d'attente », une ligne « Flow »
  réordonne tout ce qui suit le titre en cours pour que chaque morceau enchaîne sur le
  précédent par tempo (à l'octave près : 85 et 170 BPM vont ensemble), tonalité compatible
  (roue de Camelot : même case, voisines, relatives majeur/mineur) et énergie voisine. La
  lecture ne s'interrompt pas. Un second appui (« Rétablir ») remet l'ordre d'avant tant que
  la file n'a pas bougé. Un appui long choisit l'arc : *Stable*, *Montée* (l'énergie monte),
  *Vague* (monte puis redescend aux deux tiers).
- **Pourquoi ce titre** : quand le Flow est actif, le lecteur affiche sous la barre d'actions
  pourquoi le titre suivant vient là : « 127 → 129 BPM · 8A → 9A, voisines · énergie +0,1 ».
  La même ligne apparaît dans la feuille de la file.
- **Flow du jour** (Accueil › Tes mixs du jour) : jusqu'à 25 titres que tu aimes (favoris,
  notés 4 étoiles ou plus, écoutés dans les 90 derniers jours), tous analysés, enchaînés en
  vague. Sous-titre « 25 titres qui s'enchaînent, 110 → 128 → 104 BPM ». Absent tant que
  moins de 8 de ces titres ont été analysés.
- **Playlists à règles** : nouveau tri « Flow » (après filtrage, les titres s'enchaînent ;
  les non analysés viennent à la fin).

### Sous le capot
- `FlowEngine` (pur, testé) : coût `0,5 × Δbpm_rel + 0,35 × camelot/3 + 0,15 × |Δénergie|`,
  tolérance d'octave `min(|a−b|, |a−2b|, |2a−b|) / max(a, b)`, pénalité 0,25 si même artiste
  que l'un des deux précédents, 0,6 pour un titre sans données ; plus proche voisin glouton
  depuis le titre courant puis 2-opt borné à 2 000 échanges ; arcs par pénalité 0,3 sur les
  variations d'énergie à contre-sens.
- File : `MediaController.replaceMediaItems(courant + 1, fin, réordonnés)` — un seul
  événement de timeline, aucune coupure. Le mode aléatoire est coupé à l'activation. L'état
  Flow (arc, ordre d'avant, instantané des identifiants) vit en mémoire dans
  `PlayerConnection` et tombe dès que la file change autrement que par le Flow.
- `DailyMixKind.FLOW`, `DailyMixRepository` lit aussi les notes et les traits.
- `SmartSort.FLOW` dans `RulePlaylistEngine`.
- Aucun nouveau réglage, schéma Room inchangé (17). 552 tests JVM (+ 16).

### Écarts assumés avec la spec §7
- `flowActive` n'est pas persisté : après un redémarrage du processus, la file restaurée garde
  l'ordre Flow mais pas l'explication ni l'état du bouton.
- Pas de section « À suivre » dans le lecteur : la ligne « Pourquoi ce titre » est sous la
  barre d'actions (« File · N ») et dans la feuille de la file.
- `RulePlaylistRules` n'a pas de champ `flow` : le tri `SmartSort.FLOW` suffit.
- « Caler sur l'énergie » (5.16.0) s'applique à toute file, Flow ou non : le Flow n'ajoute pas
  de condition sur `outroMs` / `introMs`.
- Au moins deux titres analysés après le courant sont nécessaires ; sinon un message le dit
  et la file n'est pas touchée. La passe 2-opt est sautée au-delà de 400 titres.

### Checklist téléphone
- [ ] Lancer une file d'environ 30 titres analysés (album ou playlist), ouvrir « File », appuyer sur « Flow » : la lecture continue sans coupure, l'ordre après le titre courant change, le titre courant reste à sa place.
- [ ] Sous la barre d'actions du lecteur, « Pourquoi ce titre : … » est cohérent avec le titre suivant (BPM proches ou à l'octave, tonalités voisines ou identiques).
- [ ] Second appui (« Rétablir ») : l'ordre d'avant revient exactement.
- [ ] Appui long sur le bouton : menu Stable / Montée / Vague ; choisir « Montée » : l'énergie des titres suivants monte globalement, le libellé devient « Flow · Montée ».
- [ ] Retirer ou ajouter un titre à la file pendant le Flow : l'explication disparaît, un nouvel appui recalcule.
- [ ] File avec titres non analysés (podcasts, ajouts récents) : ils se retrouvent en fin ; file sans titres analysés : message « pas assez de titres analysés », rien ne bouge.
- [ ] Mode aléatoire actif puis Flow : l'aléatoire se coupe, l'ordre Flow s'applique.
- [ ] Accueil › Tes mixs du jour : carte « Flow du jour » présente si au moins 8 titres aimés sont analysés, sous-titre avec trois BPM ; la lancer joue dans l'ordre composé.
- [ ] Playlist à règles : tri « Flow » → ordre qui s'enchaîne, titres non analysés en fin ; « Décroissant » sans effet.
- [ ] Fondu 6 s + « Caler sur l'énergie » + Flow : les enchaînements se font sur la vraie fin du son.
- [ ] Montre : télécommande inchangée.
