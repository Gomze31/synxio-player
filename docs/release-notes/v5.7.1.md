# Synxio Player 5.7.1

## Lecteur

- Le lecteur plein écran se ferme en le tirant vers le bas, et s'ouvre en tirant le mini-lecteur vers le haut : il suit ton doigt. Le retour système montre un aperçu avant de le refermer.
- Le mini-lecteur se range d'un balayage vers le bas : la lecture se met en pause, et « Annuler » la reprend.
- Retour haptique sur lecture/pause, cœur, onglets, barre de progression et balayages. Débrayable dans Réglages → Apparence → Mouvement et lumière → « Retour haptique ».

## Sous le capot

- La position de lecture ne fait plus se redessiner toute l'interface quatre fois par seconde : seuls la barre de progression, les paroles et les chapitres suivent le temps.
