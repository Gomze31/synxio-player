# Au poignet 5.10.0 — plan 1 : protocole et côté téléphone

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Le téléphone publie son état de lecture sur le Wearable Data Layer et exécute les commandes qu'une montre lui envoie ; le modèle et les constantes du protocole vivent dans un module JVM pur partagé avec la future appli montre.

**Architecture:** `:wear-protocol` (Kotlin JVM, kotlinx.serialization) définit `WearPaths`, `WearState` et `WearCommand`. Dans `:app`, `WearBridge` (singleton Hilt, même patron que `WidgetUpdater`) convertit le `WidgetSnapshot` déjà calculé par `PlaybackService.refreshWidgetSoon()` en `WearState`, dédoublonne, prépare la pochette en JPEG 160 px et confie le tout à `WearStatePublisher` (interface ; implémentation `DataLayerStatePublisher`). `WearCommandService` (`WearableListenerService`) reçoit les messages `/synxio/cmd`, les parse en `WearCommand`, ouvre un `MediaController` sur `PlaybackService` et délègue à `WearCommandExecutor`, pur, testé contre un `PlaybackTarget` factice.

**Tech Stack:** Kotlin 2.4.21 (JVM pur pour `:wear-protocol`, Kotlin intégré à AGP 9.4.1 pour `:app`), kotlinx.serialization 1.12.0, `play-services-wearable` 20.0.1, `kotlinx-coroutines-play-services` 1.11.0 (déjà présent), Media3 1.11.1, Hilt 2.60.1, JUnit 4.

**Spec:** `docs/superpowers/specs/2026-11-19-wear-os-5.10.0-design.md` (sections « Décisions », 1, 3.2, 3.3)

## Global Constraints

- `applicationId` du téléphone inchangé : `fr.synxio.player` (debug : `fr.synxio.player.debug`). L'appli montre (plan 2) utilisera le même identifiant.
- Chemins et constantes exacts : `/synxio/state`, `/synxio/cmd`, capacité `synxio_phone`, `PROTOCOL_VERSION = 1`. Clés de la `DataMap` : `state` (JSON), `art` (Asset JPEG 160 px), `artBlurred` (Asset JPEG 160 px).
- Encodage des commandes (chaîne UTF-8) : `play_pause`, `next`, `previous`, `toggle_favorite`, `volume_up`, `volume_down`, `volume:<0..1>`, `seek:<ms>`, `start:<mediaId>`. Toute autre chaîne, un niveau hors `[0, 1]`, une position négative ou un `mediaId` vide → `parse` renvoie `null`.
- Le service ne plante jamais pour la montre : toute exception Play Services est attrapée dans `WearBridge` / `DataLayerStatePublisher` et journalisée sous le tag `SynxioWear` en `Log.w`.
- Pochette : 160 px, JPEG qualité 80. Flou : réduction à 16 px puis remontée à 160 px avec filtrage (écart assumé par rapport au spec §1.2 « flou gaussien rayon 24 » : pas de `RenderEffect` hors écran sous API 31, et le résultat visuel est équivalent à cette taille).
- Pas de filtre `CAPABILITY_CHANGED` sur `WearCommandService` (écart assumé par rapport au spec §1.2 : aucun traitement associé en V1).
- Signature release dupliquée dans `:wear` au plan 2 plutôt qu'un script partagé `gradle/signing.gradle.kts` (écart assumé par rapport au spec §3.3 : `apply(from = …)` n'offre pas d'accesseurs typés AGP).

```kotlin
package fr.synxio.player.wear.protocol

import kotlinx.serialization.Serializable
import kotlinx.serialization.encodeToString
import kotlinx.serialization.json.Json

/**
 * Photo de la lecture telle que la montre la reçoit.
 *
 * La montre ne reçoit pas de tick par seconde : elle extrapole la position depuis
 * [positionMs] et [capturedAtMs] tant que [isPlaying]. Le téléphone republie à chaque
 * transition (piste, lecture/pause, favori, volume), jamais en continu.
 */
@Serializable
data class WearState(
    val protocolVersion: Int = WearPaths.PROTOCOL_VERSION,
    val mediaId: String = "",
    val title: String = "",
    val artist: String = "",
    val isPlaying: Boolean = false,
    val favorite: Boolean = false,
    val positionMs: Long = 0L,
    val durationMs: Long = 0L,
    /** Horloge murale (`System.currentTimeMillis`) de la photo. */
    val capturedAtMs: Long = 0L,
    val live: Boolean = false,
    val hasNext: Boolean = false,
    val shuffle: Boolean = false,
    val repeatMode: Int = 0,
    /** Volume du flux musique, de 0 à 1. */
    val volume: Float = 0f,
    /** Accent ARGB lu sur fond sombre ; 0 quand la pochette n'en donne pas. */
    val accent: Int = 0,
    val accentLight: Int = 0,
) {
    val isEmpty: Boolean get() = mediaId.isEmpty()

    /** Position estimée à [nowMs], bornée à la durée. */
    fun progressAt(nowMs: Long): Long {
        val elapsed = if (isPlaying && capturedAtMs > 0L) (nowMs - capturedAtMs).coerceAtLeast(0L) else 0L
        val position = positionMs + elapsed
        return if (durationMs > 0L) position.coerceIn(0L, durationMs) else position.coerceAtLeast(0L)
    }

    /** Fraction 0..1 pour un anneau de progression ; 0 pour un direct ou sans durée. */
    fun progressFractionAt(nowMs: Long): Float {
        if (durationMs <= 0L || live) return 0f
        return (progressAt(nowMs).toFloat() / durationMs).coerceIn(0f, 1f)
    }

    /**
     * Vrai si l'état dit « en lecture » depuis plus de [STALE_MS] sans republication :
     * le téléphone a sans doute redémarré. La montre l'affiche alors en pause.
     */
    fun isStaleAt(nowMs: Long): Boolean = isPlaying && nowMs - capturedAtMs > STALE_MS

    fun toJson(): String = json.encodeToString(this)

    companion object {
        const val STALE_MS = 6 * 60 * 60 * 1000L

        private val json = Json {
            ignoreUnknownKeys = true
            encodeDefaults = true
        }

        /** `null` si le JSON est illisible : la montre garde son état précédent. */
        fun fromJson(text: String): WearState? =
            runCatching { json.decodeFromString<WearState>(text) }.getOrNull()
    }
}
```

```kotlin
package fr.synxio.player.wear.protocol

/**
 * Commande envoyée par la montre au téléphone, encodée en une chaîne UTF-8 courte.
 *
 * Les chaînes sont stables : une montre plus ancienne reste comprise par un téléphone
 * plus récent, et inversement, tant que [WearPaths.PROTOCOL_VERSION] ne change pas.
 */
sealed interface WearCommand {
    data object PlayPause : WearCommand
    data object Next : WearCommand
    data object Previous : WearCommand
    data object ToggleFavorite : WearCommand
    data object VolumeUp : WearCommand
    data object VolumeDown : WearCommand

    /** Niveau absolu de 0 à 1. Non utilisé par l'interface V1. */
    data class Volume(val level: Float) : WearCommand

    /** Non utilisé par l'interface V1. */
    data class Seek(val positionMs: Long) : WearCommand

    /** Lance une file à partir d'un identifiant `synxio://…` résolu par `onSetMediaItems`. */
    data class Start(val mediaId: String) : WearCommand

    fun encode(): String = when (this) {
        PlayPause -> "play_pause"
        Next -> "next"
        Previous -> "previous"
        ToggleFavorite -> "toggle_favorite"
        VolumeUp -> "volume_up"
        VolumeDown -> "volume_down"
        is Volume -> "volume:$level"
        is Seek -> "seek:$positionMs"
        is Start -> "start:$mediaId"
    }

    companion object {
        /** `null` pour toute charge inconnue ou hors bornes : la commande est ignorée. */
        fun parse(payload: String): WearCommand? {
            when (payload) {
                "play_pause" -> return PlayPause
                "next" -> return Next
                "previous" -> return Previous
                "toggle_favorite" -> return ToggleFavorite
                "volume_up" -> return VolumeUp
                "volume_down" -> return VolumeDown
            }
            val separator = payload.indexOf(':')
            if (separator <= 0) return null
            val key = payload.substring(0, separator)
            val value = payload.substring(separator + 1)
            return when (key) {
                "volume" -> value.toFloatOrNull()?.takeIf { it in 0f..1f }?.let(::Volume)
                "seek" -> value.toLongOrNull()?.takeIf { it >= 0L }?.let(::Seek)
                "start" -> value.takeIf { it.isNotEmpty() }?.let(::Start)
                else -> null
            }
        }
    }
}

/** Identifiants de lancement rapide, miroir de `BrowseIds` côté téléphone. */
object WearStartIds {
    const val LAST_QUEUE = "synxio://last-queue"
    const val FAVORITES = "synxio://favorites"
    const val SHUFFLE_ALL = "synxio://shuffle/all"
    const val SURPRISE = "synxio://surprise"
}
```

```kotlin
import android.content.Context
import android.util.Log
import com.google.android.gms.wearable.Asset

import com.google.android.gms.wearable.Wearable

import fr.synxio.player.wear.protocol.WearPaths
import fr.synxio.player.wear.protocol.WearState
import kotlinx.coroutines.tasks.await
import javax.inject.Inject
import javax.inject.Singleton

/** Dépose l'état de lecture là où la montre le lit. Interface pour tester `WearBridge` sans Play Services. */
interface WearStatePublisher {
    /**
     * Publie [state]. [art] et [artBlurred] sont des JPEG prêts à envoyer, ou `null`
     * quand la pochette ne change pas depuis la dernière publication (l'ancienne reste
     * attachée côté montre) ou n'existe pas.
     */
    suspend fun publish(state: WearState, art: ByteArray?, artBlurred: ByteArray?)
}

/**
 * Implémentation Data Layer : un `DataItem` urgent sur [WearPaths.STATE].
 *
 * Les `Asset` ne transitent par Bluetooth que si leurs octets changent : le Data Layer
 * les compare par empreinte. Réattacher les mêmes octets ne coûte donc rien.
 */
@Singleton
class DataLayerStatePublisher @Inject constructor(
    @ApplicationContext private val context: Context,
) : WearStatePublisher {

    private var lastArt: ByteArray? = null
    private var lastArtBlurred: ByteArray? = null

    override suspend fun publish(state: WearState, art: ByteArray?, artBlurred: ByteArray?) {
        if (state.isEmpty) {
            lastArt = null
            lastArtBlurred = null
        } else {
            if (art != null) lastArt = art
            if (artBlurred != null) lastArtBlurred = artBlurred
        }
        val request = PutDataMapRequest.create(WearPaths.STATE).apply {
            dataMap.putString(WearPaths.KEY_STATE, state.toJson())
            lastArt?.let { dataMap.putAsset(WearPaths.KEY_ART, Asset.createFromBytes(it)) }
            lastArtBlurred?.let { dataMap.putAsset(WearPaths.KEY_ART_BLURRED, Asset.createFromBytes(it)) }
        }.asPutDataRequest().setUrgent()
        try {
            Wearable.getDataClient(context).putDataItem(request).await()
        } catch (e: Exception) {
            // Play Services absents ou montre jamais appairée : la lecture continue sans montre.
            Log.w(TAG, "État non publié vers la montre", e)
        }
    }

    private companion object {
        const val TAG = "SynxioWear"
    }
}
```

```kotlin
import javax.inject.Inject
import javax.inject.Singleton

/** Pochette et accents prêts pour la montre. */
data class WearArt(
    val accent: Int,
    val accentLight: Int,
    /** JPEG carré de [WearPaths.ART_PIXELS] px, ou `null` sans pochette. */
    val art: ByteArray?,
    /** Même image, floutée, pour le fond du lecteur. */
    val artBlurred: ByteArray?,
) {
    companion object {
        val NONE = WearArt(accent = 0, accentLight = 0, art = null, artBlurred = null)
    }
}

/** Interface pour tester `WearBridge` sans décoder d'image. */
interface WearArtPreparer {
    /** [artUri] : URI de la pochette, ou `null`. [key] identifie la pochette pour le cache des accents. */
    fun prepare(artUri: String?, key: String): WearArt
}

/**
 * Implémentation réelle : accents via [WidgetArtRenderer] (déjà calculés et mis en cache
 * pour les widgets), JPEG 160 px via [ArtBitmaps], flou par réduction à 16 px puis
 * remontée filtrée.
 */
@Singleton
class BitmapWearArtPreparer @Inject constructor(
    @ApplicationContext private val context: Context,
    private val renderer: WidgetArtRenderer,
) : WearArtPreparer {

    override fun prepare(artUri: String?, key: String): WearArt {
        val uri = artUri?.takeIf { it.isNotEmpty() }?.let(Uri::parse)
        val prepared = runCatching { renderer.prepare(uri, key) }.getOrNull()
        val source = uri?.let { ArtBitmaps.decode(context, it, WearPaths.ART_PIXELS) }
        val square = source?.let { squared(it, WearPaths.ART_PIXELS) }
        return WearArt(
            accent = prepared?.accentDark ?: 0,
            accentLight = prepared?.accentLight ?: 0,
            art = square?.let(::jpeg),
            artBlurred = square?.let { jpeg(blurred(it)) },
        )
    }

    private fun squared(src: Bitmap, side: Int): Bitmap {
        val size = minOf(src.width, src.height)
        val x = (src.width - size) / 2
        val y = (src.height - size) / 2
        val cropped = Bitmap.createBitmap(src, x, y, size, size)
        return if (size == side) cropped else Bitmap.createScaledBitmap(cropped, side, side, true)
    }

    private fun blurred(square: Bitmap): Bitmap {
        val tiny = Bitmap.createScaledBitmap(square, BLUR_PIXELS, BLUR_PIXELS, true)
        return Bitmap.createScaledBitmap(tiny, square.width, square.height, true)
    }

    private fun jpeg(bitmap: Bitmap): ByteArray = ByteArrayOutputStream().use { out ->
        bitmap.compress(Bitmap.CompressFormat.JPEG, JPEG_QUALITY, out)
        out.toByteArray()
    }

    private companion object {
        const val BLUR_PIXELS = 16
        const val JPEG_QUALITY = 80
    }
}
```

```kotlin
package fr.synxio.player.wear

import fr.synxio.player.wear.protocol.WearState
import kotlin.math.abs

/**
 * Décide si un nouvel état mérite un aller Bluetooth.
 *
 * Le service publie souvent (sauvegarde de position, minuteur). Pendant la lecture, la
 * montre extrapole la position : un état qui ne fait que confirmer cette extrapolation
 * n'apporte rien. Tout changement d'un autre champ, ou un saut de position, est publié.
 */
object WearStateDedup {
    const val POSITION_TOLERANCE_MS = 2_000L

    fun needsPublish(previous: WearState?, next: WearState, nowMs: Long): Boolean {
        if (previous == null) return true
        if (previous.stripped() != next.stripped()) return true
        if (!next.isPlaying) return previous.positionMs != next.positionMs
        val expected = previous.progressAt(nowMs)
        val actual = next.progressAt(nowMs)
        return abs(expected - actual) > POSITION_TOLERANCE_MS
    }

    /** Sans l'horloge ni la position : les champs dont tout changement vaut publication. */
    private fun WearState.stripped() = copy(positionMs = 0L, capturedAtMs = 0L)
}
```

```kotlin
/**
 * Pousse l'état de lecture vers la montre.
 *
 * Même place que `WidgetUpdater` : appelé par `PlaybackService.refreshWidgetSoon()` avec
 * la photo déjà calculée pour les widgets. Dédoublonne, prépare la pochette seulement
 * quand le titre change, et ne laisse jamais remonter d'exception.
 */
@Singleton
class WearBridge(
    private val publisher: WearStatePublisher,
    private val artPreparer: WearArtPreparer,
    private val volume: () -> Float,
    private val clock: () -> Long,
) {
    @Inject
    constructor(
        @ApplicationContext context: Context,
        publisher: WearStatePublisher,
        artPreparer: WearArtPreparer,
    ) : this(publisher, artPreparer, volume = { musicVolume(context) }, clock = System::currentTimeMillis)

    private val mutex = Mutex()
    private var lastState: WearState? = null
    private var lastArtKey: String? = null
    private var lastArt: WearArt = WearArt.NONE

    suspend fun publish(snapshot: WidgetSnapshot, artworkUri: String?) = withContext(Dispatchers.IO) {
        mutex.withLock {
            val now = clock()
            val artKey = if (snapshot.isEmpty) null else "${snapshot.mediaId}|${artworkUri.orEmpty()}"
            val artChanged = artKey != lastArtKey
            if (artChanged) {
                lastArt = if (artKey == null) WearArt.NONE else safePrepare(artworkUri, artKey)
                lastArtKey = artKey
            }
            val state = snapshot.toWearState(volume(), lastArt)
            if (!WearStateDedup.needsPublish(lastState, state, now)) return@withLock
            send(state, art = if (artChanged) lastArt.art else null, blurred = if (artChanged) lastArt.artBlurred else null)
        }
    }

    /** Après un changement de volume demandé par la montre : réémet le dernier état avec le niveau courant. */
    suspend fun publishVolumeOnly() = withContext(Dispatchers.IO) {
        mutex.withLock {
            val previous = lastState ?: return@withLock
            val state = previous.copy(volume = volume(), capturedAtMs = clock(), positionMs = previous.progressAt(clock()))
            send(state, art = null, blurred = null)
        }
    }

    private suspend fun send(state: WearState, art: ByteArray?, blurred: ByteArray?) {
        try {
            publisher.publish(state, art, blurred)
            lastState = state
        } catch (e: Exception) {
            Log.w(TAG, "État non publié vers la montre", e)
        }
    }

    private fun safePrepare(artworkUri: String?, key: String): WearArt =
        try {
            artPreparer.prepare(artworkUri, key)
        } catch (e: Exception) {
            Log.w(TAG, "Pochette non préparée pour la montre", e)
            WearArt.NONE
        }

    private fun WidgetSnapshot.toWearState(volume: Float, art: WearArt) = WearState(
        mediaId = mediaId,
        title = title,
        artist = artist,
        isPlaying = isPlaying,
        favorite = favorite,
        positionMs = positionMs,
        durationMs = durationMs,
        capturedAtMs = capturedAtMs,
        live = live,
        hasNext = hasNext,
        shuffle = shuffle,
        repeatMode = repeatMode,
        volume = volume,
        accent = art.accent,
        accentLight = art.accentLight,
    )

    private companion object {
        const val TAG = "SynxioWear"

        fun musicVolume(context: Context): Float {
            val audio = context.getSystemService(AudioManager::class.java) ?: return 0f
            val max = audio.getStreamMaxVolume(AudioManager.STREAM_MUSIC).coerceAtLeast(1)
            return audio.getStreamVolume(AudioManager.STREAM_MUSIC).toFloat() / max
        }
    }
}
```

```kotlin
import android.media.AudioManager
import kotlin.math.roundToInt

/** Volume du flux musique, piloté par la couronne de la montre. */
interface VolumeControl {
    fun raise()
    fun lower()
    /** [level] de 0 à 1. */
    fun set(level: Float)
}

class StreamVolumeControl(private val audio: AudioManager) : VolumeControl {
    override fun raise() = audio.adjustStreamVolume(AudioManager.STREAM_MUSIC, AudioManager.ADJUST_RAISE, AudioManager.FLAG_SHOW_UI)
    override fun lower() = audio.adjustStreamVolume(AudioManager.STREAM_MUSIC, AudioManager.ADJUST_LOWER, AudioManager.FLAG_SHOW_UI)
    override fun set(level: Float) {
        val max = audio.getStreamMaxVolume(AudioManager.STREAM_MUSIC)
        audio.setStreamVolume(AudioManager.STREAM_MUSIC, (level.coerceIn(0f, 1f) * max).roundToInt(), AudioManager.FLAG_SHOW_UI)
    }
}
```

```kotlin
package fr.synxio.player.wear

import fr.synxio.player.wear.protocol.WearCommand
import fr.synxio.player.wear.protocol.WearStartIds

/**
 * Table commande montre → action sur le téléphone.
 *
 * Sans file chargée (service tout juste démarré), lecture/pause reprend la dernière file ;
 * les autres commandes de transport n'ont rien sur quoi agir et sont ignorées.
 */
class WearCommandExecutor(
    private val target: PlaybackTarget,
    private val volume: VolumeControl,
) {
    /** @return vrai si le volume a changé : l'appelant republie alors l'état. */
    fun execute(command: WearCommand): Boolean {
        when (command) {
            WearCommand.PlayPause -> if (target.hasQueue) target.playPause() else target.start(WearStartIds.LAST_QUEUE)
            WearCommand.Next -> if (target.hasQueue) target.next()
            WearCommand.Previous -> if (target.hasQueue) target.previous()
            WearCommand.ToggleFavorite -> if (target.hasQueue) target.toggleFavorite()
            is WearCommand.Seek -> if (target.hasQueue) target.seekTo(command.positionMs)
            is WearCommand.Start -> target.start(command.mediaId)
            WearCommand.VolumeUp -> { volume.raise(); return true }
            WearCommand.VolumeDown -> { volume.lower(); return true }
            is WearCommand.Volume -> { volume.set(command.level); return true }
        }
        return false
    }
}
```

```kotlin
package fr.synxio.player.wear

import android.content.ComponentName
import android.media.AudioManager
import android.util.Log
import androidx.media3.session.MediaController
import androidx.media3.session.SessionToken
import com.google.android.gms.wearable.MessageEvent
import com.google.android.gms.wearable.WearableListenerService
import dagger.hilt.android.AndroidEntryPoint
import fr.synxio.player.playback.PlaybackService
import fr.synxio.player.wear.protocol.WearCommand
import fr.synxio.player.wear.protocol.WearPaths
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.SupervisorJob
import kotlinx.coroutines.cancel
import kotlinx.coroutines.guava.await
import kotlinx.coroutines.launch
import kotlinx.coroutines.withTimeoutOrNull
import javax.inject.Inject

/**
 * Reçoit les commandes de la montre et les joue sur `PlaybackService`.
 *
 * Play Services démarrent ce service à chaque message, même appli fermée. Un
 * `MediaController` est ouvert le temps de la commande : sa construction démarre
 * `PlaybackService` s'il ne tourne pas, ce qui suffit à « Reprendre » depuis la montre.
 */
@AndroidEntryPoint
class WearCommandService : WearableListenerService() {

    @Inject lateinit var wearBridge: WearBridge

    private val scope = CoroutineScope(SupervisorJob() + Dispatchers.Main)

    override fun onMessageReceived(event: MessageEvent) {
        if (event.path != WearPaths.COMMAND) return
        val command = WearCommand.parse(String(event.data, Charsets.UTF_8))
        if (command == null) {
            Log.w(TAG, "Commande montre ignorée : ${String(event.data, Charsets.UTF_8)}")
            return
        }
        scope.launch { run(command) }
    }

    private suspend fun run(command: WearCommand) {
        val token = SessionToken(this, ComponentName(this, PlaybackService::class.java))
        val future = MediaController.Builder(this, token).buildAsync()
        val controller = withTimeoutOrNull(CONNECT_TIMEOUT_MS) { runCatching { future.await() }.getOrNull() }
        if (controller == null) {
            Log.w(TAG, "Lecteur injoignable en ${CONNECT_TIMEOUT_MS} ms : $command abandonnée")
            MediaController.releaseFuture(future)
            return
        }
        try {
            val audio = getSystemService(AudioManager::class.java)
            val volumeChanged = WearCommandExecutor(ControllerTarget(controller), StreamVolumeControl(audio)).execute(command)
            if (volumeChanged) wearBridge.publishVolumeOnly()
        } finally {
            MediaController.releaseFuture(future)
        }
    }

    override fun onDestroy() {
        scope.cancel()
        super.onDestroy()
    }

    private companion object {
        const val TAG = "SynxioWear"
        const val CONNECT_TIMEOUT_MS = 5_000L
    }
}
```
