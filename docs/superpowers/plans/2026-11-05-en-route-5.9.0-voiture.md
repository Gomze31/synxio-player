# En route 5.9.0 — plan 3 : mode voiture 2, réglages, release

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pour les voitures sans Android Auto : Synxio reconnaît la voiture au Bluetooth (classe « audio de voiture » ou liste « Mes voitures »), propose ou lance ce que l'utilisateur a réglé (notification, lecture, mode voiture), quitte ou met en pause à la déconnexion, et le mode voiture devient complet : écran allumé au maximum, thème sombre, file des trois titres suivants, cœur, aléatoire, micro. La 5.9.0 prend son numéro et ses notes.

**Architecture:** Décisions pures dans `core/car` (`CarRules.isCar`, `carActions`, `DriveQueue.upcoming`), testées sur la JVM. `CarDetector` (construit comme `BudsMonitor`) expose `connected: StateFlow<CarDevice?>` ; `PlaybackService` l'observe et exécute les actions (notification « Voiture détectée », lecture, ouverture du mode voiture si l'app est visible, pause). `AppVisibility` (objet, alimenté par `MainActivity`) dit si l'app est au premier plan. Les réglages passent par `SettingsRepository` ; un sous-menu « Voiture » les regroupe. `DriveModeScreen` gagne la file, les boutons et la gestion de l'écran.

**Tech Stack:** Kotlin 2.4, Compose BOM 2026.09, Hilt, DataStore, Bluetooth (`BLUETOOTH_CONNECT` déjà déclarée), notifications (`POST_NOTIFICATIONS` déjà déclarée), JUnit 4.

**Spec:** `docs/superpowers/specs/2026-11-05-android-auto-5.9.0-design.md` (sections 3, 4, 5)

- Réglages, tous désactivés par défaut : « Proposer le mode voiture » (`carNotify`, clé `car_notify`), « Lancer la lecture » (`carAutoPlay`, `car_auto_play`) avec sa source (`carPlaySource`, `car_play_source`, `CarPlaySource { RESUME, DAILY_MIX, FAVORITES, PLAYLIST }`, défaut `RESUME`) et sa playlist (`carPlaylistId`, `car_playlist_id`, défaut −1), « Ouvrir le mode voiture automatiquement » (`carOpenDriveMode`, `car_open_drive_mode`), « Quitter avec la voiture » (`carExitWithCar`, `car_exit_with_car`), « Mettre en pause à la déconnexion » (`carPauseOnDisconnect`, `car_pause_on_disconnect`) ; « Mes voitures » (`carAddresses: Set<String>`, `car_addresses`).

`CarActions.kt` :

```kotlin
package fr.synxio.player.core.car

enum class CarEvent { CONNECTED, DISCONNECTED }

/** Ce que « Lancer la lecture » démarre quand la voiture se connecte. */
enum class CarPlaySource(val label: String) {
    RESUME("Reprendre la file"),
    DAILY_MIX("Mix du jour"),
    FAVORITES("Favoris en aléatoire"),
    PLAYLIST("Une playlist"),
}

/** Les réglages Voiture, tels que [carActions] les lit. */
data class CarSettings(
    val notify: Boolean,
    val autoPlay: Boolean,
    val playSource: CarPlaySource,
    val playlistId: Long,
    val openDriveMode: Boolean,
    val exitWithCar: Boolean,
    val pauseOnDisconnect: Boolean,
)

sealed interface CarAction {
    /** Notification « Voiture détectée », avec ses deux boutons. */
    data object Notify : CarAction
    data class StartPlayback(val source: CarPlaySource, val playlistId: Long) : CarAction
    /** Ouvrir l'écran du mode voiture : seulement quand l'app est déjà visible. */
    data object OpenDriveMode : CarAction
    data object DismissNotification : CarAction
    data object ExitDriveMode : CarAction
    data object Pause : CarAction
}

/**
 * Réglages + événement → actions, dans l'ordre d'exécution.
 *
 * Android interdit d'ouvrir une activité depuis l'arrière-plan : « Ouvrir automatiquement »
 * se replie alors sur la notification, même si « Proposer » est coupé.
 */
fun carActions(event: CarEvent, settings: CarSettings, foreground: Boolean): List<CarAction> = when (event) {
    CarEvent.CONNECTED -> buildList {
        if (settings.autoPlay) add(CarAction.StartPlayback(settings.playSource, settings.playlistId))
        when {
            settings.openDriveMode && foreground -> add(CarAction.OpenDriveMode)
            settings.notify || settings.openDriveMode -> add(CarAction.Notify)
        }
    }
    CarEvent.DISCONNECTED -> buildList {
        add(CarAction.DismissNotification)
        if (settings.exitWithCar) add(CarAction.ExitDriveMode)
        if (settings.pauseOnDisconnect) add(CarAction.Pause)
    }
}
```

package fr.synxio.player.core.car

import fr.synxio.player.data.model.RepeatMode

/** Les titres qui suivent, pour la file simplifiée du mode voiture. */
object DriveQueue {
    /**
     * Index des [count] titres suivants : jusqu'à la fin en lecture simple, en boucle
     * sans repasser par le titre courant quand la file se répète, aucun quand le titre
     * se répète. Vide si la file est vide ou l'index hors de la file.
     */
    fun upcoming(size: Int, index: Int, repeat: RepeatMode, count: Int = 3): List<Int> {
        if (size <= 0 || index !in 0 until size || repeat == RepeatMode.ONE) return emptyList()
        val available = if (repeat == RepeatMode.ALL) size - 1 else size - 1 - index
        return (1..minOf(count, available)).map { (index + it) % size }
    }
}

package fr.synxio.player.core.util

import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow

/**
 * L'app est-elle à l'écran ? Alimenté par `MainActivity` (`onStart` / `onStop`). Remplace
 * `ProcessLifecycleOwner`, dont la bibliothèque n'est pas dépendue : une seule activité,
 * un compteur suffit.
 */
object AppVisibility {
    private val _foreground = MutableStateFlow(false)
    val foreground: StateFlow<Boolean> = _foreground.asStateFlow()
    private var started = 0

    fun onStart() { started++; _foreground.value = true }
    fun onStop() { started = (started - 1).coerceAtLeast(0); _foreground.value = started > 0 }
}

/**
 * Suit la voiture connectée en Bluetooth, comme `BudsMonitor` suit les Galaxy Buds.
 *
 * Une voiture, c'est un appareil de classe « audio de voiture » ou une adresse cochée dans
 * « Mes voitures ». Les connexions arrivent par les diffusions ACL de la pile Bluetooth,
 * réservées aux applis qui ont BLUETOOTH_CONNECT (Android 12+) ; sans elle, rien n'est
 * détecté. Partagé en continu : le service agit sur chaque connexion tant que le
 * processus vit.
 */
@OptIn(ExperimentalCoroutinesApi::class)
@Singleton
class CarDetector @Inject constructor(
    @ApplicationContext private val context: Context,
    settings: SettingsRepository,
    @ApplicationScope scope: CoroutineScope,
) {
    private val permissionChanges = MutableStateFlow(0)

    val connected: StateFlow<CarDevice?> = combine(
        permissionChanges,
        settings.settings.map { it.carAddresses }.distinctUntilChanged(),
    ) { _, chosen -> chosen }
        .flatMapLatest { chosen -> carFlow(chosen) }
        .distinctUntilChanged()
        .stateIn(scope, SharingStarted.Eagerly, null)

    fun hasBluetoothPermission(): Boolean =
        Build.VERSION.SDK_INT < Build.VERSION_CODES.S ||
            ContextCompat.checkSelfPermission(context, Manifest.permission.BLUETOOTH_CONNECT) == PackageManager.PERMISSION_GRANTED

    /** À appeler après la demande de permission : le récepteur s'inscrit alors. */
    fun onPermissionChanged() = permissionChanges.update { it + 1 }

    /** Appareils appairés, pour cocher « Mes voitures ». Vide sans permission. */
    @Suppress("MissingPermission")
    fun bondedDevices(): List<CarDevice> {
        if (!hasBluetoothPermission()) return emptyList()
        val adapter = context.getSystemService(BluetoothManager::class.java)?.adapter ?: return emptyList()
        return runCatching { adapter.bondedDevices.orEmpty() }.getOrDefault(emptySet())
            .map { CarDevice(it.address, it.displayName() ?: it.address) }
            .sortedBy { it.name.lowercase() }
    }

    @Suppress("MissingPermission")
    private fun carFlow(chosen: Set<String>): Flow<CarDevice?> = callbackFlow {
        if (!hasBluetoothPermission()) {
            trySend(null)
            awaitClose { }
            return@callbackFlow
        }
        var current: CarDevice? = null

        fun carOf(device: BluetoothDevice): CarDevice? {
            val deviceClass = runCatching { device.bluetoothClass?.deviceClass }.getOrNull() ?: 0
            if (!CarRules.isCar(deviceClass, device.address.orEmpty(), chosen)) return null
            return CarDevice(device.address, device.displayName() ?: device.address)
        }

        val receiver = object : BroadcastReceiver() {
            override fun onReceive(context: Context, intent: Intent) {
                val device = IntentCompat.getParcelableExtra(intent, BluetoothDevice.EXTRA_DEVICE, BluetoothDevice::class.java) ?: return
                when (intent.action) {
                    BluetoothDevice.ACTION_ACL_CONNECTED -> carOf(device)?.let { current = it; trySend(it) }
                    BluetoothDevice.ACTION_ACL_DISCONNECTED -> if (current?.address == device.address) { current = null; trySend(null) }
                }
            }
        }

        // État initial : une voiture déjà branchée comme sortie audio, retrouvée parmi les appareils appairés.
        val audioManager = context.getSystemService(AudioManager::class.java)
        val adapter = context.getSystemService(BluetoothManager::class.java)?.adapter
        val outputs = runCatching { audioManager?.getDevices(AudioManager.GET_DEVICES_OUTPUTS) }.getOrNull().orEmpty()
            .filter { it.type == AudioDeviceInfo.TYPE_BLUETOOTH_A2DP }
            .mapNotNull { it.productName?.toString()?.trim() }
        current = runCatching { adapter?.bondedDevices.orEmpty() }.getOrDefault(emptySet())
            .firstOrNull { (it.displayName() ?: it.address) in outputs }
            ?.let(::carOf)
        trySend(current)

        val filter = IntentFilter().apply {
            addAction(BluetoothDevice.ACTION_ACL_CONNECTED)
            addAction(BluetoothDevice.ACTION_ACL_DISCONNECTED)
        }
        runCatching { ContextCompat.registerReceiver(context, receiver, filter, ContextCompat.RECEIVER_EXPORTED) }
        awaitClose { runCatching { context.unregisterReceiver(receiver) } }
    }

    /** Nom affiché : le surnom donné par l'utilisateur (Android 11+), sinon le nom. */
    @Suppress("MissingPermission")
    private fun BluetoothDevice.displayName(): String? =
        runCatching { (if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.R) alias ?: name else name)?.trim() }.getOrNull()
}

        if (activePlayer.isPlaying) return

                activePlayer.prepare()
