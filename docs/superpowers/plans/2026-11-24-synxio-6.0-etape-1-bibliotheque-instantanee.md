# Synxio 6.0 — Étape 1 : Bibliothèque instantanée — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** La bibliothèque s'affiche depuis un cache Room dès le démarrage, puis se synchronise avec MediaStore par scan différentiel ; les filtres utilisateur s'appliquent sans rescan ; `resolveSong` ne scanne plus.

**Architecture:** Nouvelle table Room `songs` (lignes brutes MediaStore) + `library_scan_state` (génération, version du scanner). `LibrarySync` orchestre cache → publication → scan incrémental (`GENERATION_MODIFIED` sur Android 11+, complet avant). `LibraryBuilder` (pur) remplace `MusicRepository.buildLibrary` et applique les filtres à la publication. Le modèle `Library` et les écrans ne changent pas, sauf un drapeau `isRefreshing`.

**Tech Stack:** Kotlin, Room 2.8.5 (KSP, schémas exportés), Hilt 2.60.1, coroutines/Flow, MediaStore, JUnit4 + `sqlite-jdbc` pour les migrations.

**Spec:** `docs/superpowers/specs/2026-11-24-synxio-6.0-flow-design.md` — §1 (Bibliothèque instantanée), §3 dernier point (`distinctUntilChanged`), §5.4 (colonnes `audio_features`, créées dans la même migration), §12.3 étape 1.

```kotlin
package fr.synxio.player.data.db

import androidx.room.Dao
import androidx.room.Query
import androidx.room.Transaction
import androidx.room.Upsert
import kotlinx.coroutines.flow.Flow

@Dao
abstract class LibrarySongDao {

    @Query("SELECT * FROM songs")
    abstract suspend fun all(): List<LibrarySongEntity>

    @Query("SELECT * FROM songs WHERE id = :id")
    abstract suspend fun byId(id: Long): LibrarySongEntity?

    @Query("SELECT id FROM songs")
    abstract suspend fun ids(): List<Long>

    @Query("SELECT COUNT(*) FROM songs")
    abstract suspend fun count(): Int

    @Upsert
    abstract suspend fun upsertAll(songs: List<LibrarySongEntity>)

    /** SQLite limite les variables liées : on supprime par paquets de 500. */
    @Query("DELETE FROM songs WHERE id IN (:ids)")
    protected abstract suspend fun deleteChunk(ids: List<Long>)

    suspend fun deleteByIds(ids: Collection<Long>) {
        ids.chunked(500).forEach { deleteChunk(it) }
    }

    @Query("DELETE FROM songs")
    abstract suspend fun clear()

    @Query("SELECT * FROM library_scan_state WHERE id = 0")
    abstract suspend fun scanState(): LibraryScanStateEntity?

    @Query("SELECT * FROM library_scan_state WHERE id = 0")
    abstract fun observeScanState(): Flow<LibraryScanStateEntity?>

    @Upsert
    abstract suspend fun saveScanState(state: LibraryScanStateEntity)

    @Query("DELETE FROM library_scan_state")
    abstract suspend fun clearScanState()

    /** Remplacement atomique : utilisé par le scan complet. */
    @Transaction
    open suspend fun replaceAll(songs: List<LibrarySongEntity>, state: LibraryScanStateEntity) {
        clear()
        upsertAll(songs)
        saveScanState(state)
    }

    /** Application atomique d'un diff : utilisé par le scan incrémental. */
    @Transaction
    open suspend fun applyDiff(upserts: List<LibrarySongEntity>, deletions: Collection<Long>, state: LibraryScanStateEntity) {
        if (upserts.isNotEmpty()) upsertAll(upserts)
        if (deletions.isNotEmpty()) deleteByIds(deletions)
        saveScanState(state)
    }
}
```

`app/src/main/java/fr/synxio/player/data/model/LibraryBuilder.kt` — le corps des regroupements est **déplacé tel quel** depuis `MusicRepository.buildLibrary` (`MusicRepository.kt:384-459`) :

```kotlin
package fr.synxio.player.data.model

import fr.synxio.player.data.repo.Library

/** Filtres utilisateur appliqués à la publication, jamais au scan (voir `LibrarySongEntity`). */
data class LibraryFilters(
    val minDurationMs: Long,
    val excludedFolders: Set<String>,
    val audiobookFolders: Set<String>,
)

/**
 * Construit la bibliothèque à partir des titres bruts.
 *
 * Pur : aucune dépendance Android, pour être testé en JVM. Les regroupements (albums,
 * artistes, genres, dossiers) sont ceux de l'ancien `MusicRepository.buildLibrary`.
 */
object LibraryBuilder {

    fun build(raw: List<Song>, filters: LibraryFilters, isRefreshing: Boolean = false): Library {
        val allSongs = raw.asSequence()
            .filter { it.durationMs >= filters.minDurationMs }
            .filter { song -> filters.excludedFolders.none { song.path.startsWith(it) } }
            .map { song ->
                if (!song.isAudiobook && filters.audiobookFolders.any { song.path.startsWith(it) }) song.copy(isAudiobook = true) else song
            }
            .toList()

        val podcasts = allSongs.filter { it.isPodcast }.sortedBy { it.title.lowercase() }
        val audiobooks = allSongs.filter { it.isAudiobook }.sortedBy { it.title.lowercase() }
        val musicSongs = allSongs.filter { !it.isPodcast && !it.isAudiobook }

        val albums = musicSongs
            .groupBy { it.albumId }
            .map { (albumId, albumSongs) ->
                val head = albumSongs.first()
                Album(
                    id = albumId,
                    title = head.displayAlbum,
                    artist = head.albumArtist?.takeIf { it.isNotBlank() } ?: head.displayArtist,
                    artistId = head.artistId,
                    year = albumSongs.maxOf { it.year },
                    // Ordre naturel d'écoute d'un album : disque puis piste.

                        compareBy({ it.disc }, { it.track }, { it.title.lowercase() })
                    ),
                    artworkOverride = albumSongs.firstNotNullOfOrNull { it.artworkOverride },
                )
            }

        // Un morceau peut compter pour plusieurs artistes : on indexe chaque nom
        // séparément plutôt que de créer un artiste « A/B/C » illisible.
        val albumsByArtistKey = HashMap<String, MutableSet<Album>>()
        val displayNameByKey = HashMap<String, String>()
        val artistIdByKey = HashMap<String, Long>()

        albums.forEach { album ->
            val names = album.songs
                .flatMap { song ->
                    splitArtistTag(song.albumArtist?.takeIf { it.isNotBlank() } ?: song.displayArtist)
                }
                .ifEmpty { listOf(album.artist) }

            names.distinctBy { it.lowercase() }.forEach { name ->
                val key = name.lowercase()
                albumsByArtistKey.getOrPut(key) { linkedSetOf() } += album
                displayNameByKey.putIfAbsent(key, name)
                artistIdByKey.putIfAbsent(key, album.artistId)
            }
        }

        val artists = albumsByArtistKey.map { (key, artistAlbums) ->
            Artist(
                id = artistIdByKey[key] ?: 0L,
                name = displayNameByKey[key] ?: key,
                albums = artistAlbums.sortedByDescending { it.year },
            )
        }

        val genres = musicSongs
            .groupBy { it.genre?.takeIf { g -> g.isNotBlank() } ?: Song.UNKNOWN_GENRE }
            .map { (name, genreSongs) -> Genre(name, genreSongs) }
            .sortedBy { it.name.lowercase() }

        val folders = musicSongs
            .groupBy { it.folderPath }
            .map { (path, folderSongs) -> Folder(path, folderSongs) }
            .sortedBy { it.path.lowercase() }

        return Library(
            songs = musicSongs,
            albums = albums,
            artists = artists,
            genres = genres,
            folders = folders,
            podcasts = podcasts,
            audiobooks = audiobooks,
            isLoading = false,
            hasScanned = true,
            isRefreshing = isRefreshing,
        )
    }
}
```

```kotlin
data class DiffPlan(val upserts: List<Long>, val deletions: Set<Long>) {
    val isEmpty: Boolean get() = upserts.isEmpty() && deletions.isEmpty()

 * Plan d'un scan incrémental : MediaStore donne les lignes modifiées depuis la dernière

object LibraryDiff {
    fun plan(cachedIds: Collection<Long>, changedIds: Collection<Long>, currentIds: Collection<Long>): DiffPlan {
        val current = currentIds.toHashSet()
        val deletions = cachedIds.filterTo(HashSet()) { it !in current }
        val upserts = changedIds.filter { it in current }
        return DiffPlan(upserts, deletions)
```

```kotlin
package fr.synxio.player.data.repo

import android.util.Log
import fr.synxio.player.data.db.LibraryScanStateEntity
import fr.synxio.player.data.db.LibrarySongDao
import fr.synxio.player.data.media.MediaStoreScanner
import fr.synxio.player.data.model.LibraryDiff
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import javax.inject.Inject
import javax.inject.Singleton

enum class SyncMode { INCREMENTAL, FULL }

data class SyncResult(val mode: SyncMode, val changed: Boolean, val durationMs: Long)

/**
 * Synchronise le cache Room avec MediaStore.
 *
 * Incrémental (Android 11+) : si la génération et le nombre d'ids n'ont pas bougé, rien
 * n'est lu ; sinon `GENERATION_MODIFIED` donne les ajouts et modifications, la liste des
 * ids donne les suppressions. Complet : tout est relu et remplacé dans une transaction.
 * L'appelant tient le verrou (`MusicRepository.refreshMutex`) : une seule synchronisation
 * à la fois.
 */
@Singleton
class LibrarySync @Inject constructor(
    private val scanner: MediaStoreScanner,
    private val dao: LibrarySongDao,
) {

    suspend fun sync(requested: SyncMode): SyncResult = withContext(Dispatchers.IO) {
        val started = System.currentTimeMillis()
        val state = dao.scanState()
        val mode = when {
            requested == SyncMode.FULL -> SyncMode.FULL
            !scanner.supportsIncremental -> SyncMode.FULL
            state == null -> SyncMode.FULL
            state.scannerVersion != MediaStoreScanner.SCANNER_VERSION -> SyncMode.FULL
            state.volumeName != scanner.volumeName() -> SyncMode.FULL
            else -> SyncMode.INCREMENTAL
        }
        val changed = runCatching {
            if (mode == SyncMode.FULL) full(started) else incremental(state!!, started)
        }.getOrElse { e ->
            Log.e(TAG, "Synchronisation $mode échouée", e)
            if (mode == SyncMode.INCREMENTAL) runCatching { full(started) }.getOrDefault(false) else false
        }
        val duration = System.currentTimeMillis() - started
        Log.i(TAG, "Synchronisation $mode : ${if (changed) "changements" else "rien à faire"} en $duration ms")
        SyncResult(mode, changed, duration)
    }

    private suspend fun full(now: Long): Boolean {
        val page = scanner.scanAll()
        dao.replaceAll(
            page.songs,
            LibraryScanStateEntity(
                lastGeneration = page.generation,
                volumeName = scanner.volumeName(),
                lastFullScanAt = now,
                lastScanAt = now,
                scannerVersion = MediaStoreScanner.SCANNER_VERSION,
            ),
        )
        return true
    }

    private suspend fun incremental(state: LibraryScanStateEntity, now: Long): Boolean {
        val generation = scanner.currentGeneration()
        val currentIds = scanner.currentIds()
        if (generation == state.lastGeneration && currentIds.size == dao.count()) {
            return false
        }
        val page = scanner.scanSince(state.lastGeneration)
        val cachedIds = dao.ids()
        val plan = LibraryDiff.plan(cachedIds, page.songs.map { it.id }, currentIds.asList())
        val keep = plan.upserts.toHashSet()
        val upserts = page.songs.filter { it.id in keep }
        dao.applyDiff(
            upserts,
            plan.deletions,
            state.copy(lastGeneration = page.generation, lastScanAt = now),
        )
        return !plan.isEmpty
    }

    /** Permission perdue : plus rien à montrer ni à croire. */
    suspend fun clear() = withContext(Dispatchers.IO) {
        dao.clear()
        dao.clearScanState()
    }

    private companion object {
        const val TAG = "LibrarySync"
    }
}
```
