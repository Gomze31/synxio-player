# En route 5.9.0 — plan 1 : l'arbre Android Auto

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** L'accueil Android Auto devient vivant (groupes Reprendre, Pour toi avec mixs et souvenirs, Raccourcis avec « Surprends-moi », Récents), les albums, playlists, genres, mixs et souvenirs se lancent d'un toucher, chaque élément porte ses actions (favori, lire ensuite, ajouter à la file, aléatoire), les livres et podcasts montrent leur progression, les pochettes arrivent à la taille de l'écran avec des mosaïques, et la permission manquante se résout depuis la voiture.

**Architecture:** Tout le modèle reste pur dans `BrowseTree` (`BrowseSource` gagne mixs, souvenirs, compteurs de lecture et dernière file ; `NodeKind.FOLDER_PLAYABLE`, `BrowseNode.progress`, `BrowseNode.actions`, `AutoAction`). `MediaLibraryTree` traduit en `MediaItem` et en extras Android Auto (clés Media3 `MediaConstants` et chaînes `AutoKeys`). `ArtworkProvider` sert les pochettes à la taille demandée (`?size=`) et des mosaïques 2×2 rendues par `MosaicRenderer`. `PlaybackService` lit les indices de racine, relaie les actions dans `onCustomCommand` et pose les extras de session (erreur résoluble, emplacements réservés).

**Tech Stack:** Kotlin 2.4, Media3 1.11.1 (`androidx.media3.session.MediaConstants`), Hilt, Room (DAO existant + deux requêtes observables), JUnit 4 (tests JVM purs), Desktop Head Unit pour le rendu.

**Spec:** `docs/superpowers/specs/2026-11-05-android-auto-5.9.0-design.md` (section 1, et §4 pour la vérification)

## Global Constraints

- Aucune nouvelle dépendance Gradle. Les actions de navigation passent par des chaînes figées dans `AutoKeys` (valeurs relevées dans `androidx.media:media:1.7.0`, dépendance transitive de media3-session, jamais importée).
- Relais des actions confirmé dans le jar `media3-session-1.11.1` : `MediaLibraryServiceLegacyStub.onCustomAction` appelle `onCustomCommandOnHandler` et lit `androidx.media.utils.extras.CUSTOM_BROWSER_ACTION_ROOT_LIST`. Reste à confirmer sur le DHU (tâche 9) ; si l'action n'arrive pas dans `onCustomCommand`, la tâche 5 est retirée du lot et consignée en dette, rien d'autre n'en dépend.
- Accueil « Pour toi » par groupes, dans cet ordre : Reprendre (Continuer l'écoute, Dernière file), Pour toi (mixs du jour, souvenirs), Raccourcis (Lecture aléatoire, Favoris, Surprends-moi), Récents (Écoutés récemment, Ajoutés récemment, Les plus écoutés). Un groupe vide est omis.
- « Surprends-moi » : 50 titres au plus, 30 favoris puis des titres joués au plus une fois, deux titres au plus par artiste, graine = numéro du jour, carte absente sous 3 titres.
- Nouveaux identifiants : `MIX_PREFIX = "synxio://mix/"`, `MEMORY_PREFIX = "synxio://memory/"`, `SURPRISE = "synxio://surprise"`, `LAST_QUEUE = "synxio://last-queue"`.
- `NodeKind.FOLDER_PLAYABLE(browsable = true, playable = true)` pour albums, playlists, genres, mixs, souvenirs. Les livres gardent `NodeKind.ALBUM` (ils se reprennent, ils ne se lancent pas depuis la tuile).
- Actions : identifiants `favorite`, `unfavorite`, `play_next`, `add_to_queue`, `shuffle`. Le cœur plein ou vide est obtenu avec deux actions distinctes, un élément n'en porte qu'une. Titres : favori ou retrait, lire ensuite, ajouter, aléatoire (du parent). Albums, playlists, genres, mixs, souvenirs : lire ensuite, ajouter, aléatoire. Radios et messages : aucune. Liste tronquée à la limite annoncée par l'hôte (`CUSTOM_BROWSER_ACTION_LIMIT`) ; sans limite annoncée, rien n'est déclaré.
- Messages d'action : « Ajouté aux favoris », « Retiré des favoris », « Sera lu ensuite », « Ajouté à la file », « Lecture aléatoire ».
- Progression : `EXTRAS_KEY_COMPLETION_STATUS` et `EXTRAS_KEY_COMPLETION_PERCENTAGE` (0..1) sur les livres, chapitres et épisodes, d'après `savedPositions` (un élément « marqué comme lu » a sa position à la fin : même calcul).
- Pochettes : taille lue dans `EXTRAS_KEY_MEDIA_ART_SIZE_PIXELS` des indices de racine, mémorisée par `uid` de navigateur ; `ArtworkProvider` accepte `?size=` (64 à 2048, carré, JPEG qualité 88, cache `cacheDir/auto-art`) sur `art/`, `folder/` et le nouveau segment `album/<id MediaStore>` ; mosaïque `mosaic/<id1,id2,id3,id4>` (identifiants de titres, 1 à 4) rendue par `MosaicRenderer`, cache `cacheDir/auto-mosaic`, fichiers de plus de 7 jours supprimés à l'écriture.
- Extras de session : `EXTRAS_KEY_SLOT_RESERVATION_SEEK_TO_PREV` et `_NEXT` toujours vrais ; sans permission de lecture, `EXTRAS_KEY_ERROR_RESOLUTION_ACTION_LABEL_COMPAT` = « Ouvrir Synxio sur le téléphone » et `_INTENT_COMPAT` = `PendingIntent` vers `MainActivity` (qui affiche elle-même l'accueil ou l'onboarding selon la permission). Un scan en cours n'est pas une erreur.
- Textes de l'interface en français, tutoiement ; KDoc et commentaires en français, pas de TODO.
- Commandes Gradle lancées depuis PowerShell (`.\gradlew.bat`), jamais depuis Git Bash. Tests JVM : `.\gradlew.bat :app:testDebugUnitTest --tests "<classe>"`.
- Chaque tâche se termine par un commit sur `dev-5.5`, message en français, suivi de la ligne `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Pas de push.
- Les tests JVM ne doivent jamais appeler `Song.artworkUri` ni `Uri` (non simulés) : `NodeArt` reste une description, la résolution en URI vit dans `MediaLibraryTree`.

```kotlin
package fr.synxio.player.playback

/**
 * Clés des actions de navigation Android Auto (menu contextuel d'un élément parcouru).
 *
 * Elles ne vivent que comme chaînes dans `androidx.media.utils.MediaConstants`
 * (androidx.media:media, dépendance transitive de media3-session, jamais importée
 * ici). Media3 1.11.1 relaie l'appel : `MediaLibraryServiceLegacyStub.onCustomAction`
 * remonte dans `MediaLibrarySession.Callback.onCustomCommand`, avec l'identifiant de
 * l'action en commande et les extras du navigateur en arguments.
 *
 * Valeurs relevées dans androidx.media:media:1.7.0 ; `AutoKeysTest` les fige.
 */
object AutoKeys {
    /** Indice de racine : nombre d'actions par élément que l'hôte sait afficher. */
    const val ROOT_HINT_ACTION_LIMIT = "androidx.media.utils.MediaBrowserCompat.extras.CUSTOM_BROWSER_ACTION_LIMIT"
    /** Extras de racine : liste (`ArrayList<Bundle>`) des actions déclarées. */
    const val ROOT_EXTRAS_ACTION_LIST = "androidx.media.utils.extras.CUSTOM_BROWSER_ACTION_ROOT_LIST"
    /** Extras d'un élément : identifiants (`ArrayList<String>`) des actions qui s'y appliquent. */
    const val ITEM_ACTION_ID_LIST = "androidx.media.utils.extras.CUSTOM_BROWSER_ACTION_ID_LIST"

    const val ACTION_ID = "androidx.media.utils.extras.KEY_CUSTOM_BROWSER_ACTION_ID"
    const val ACTION_LABEL = "androidx.media.utils.extras.KEY_CUSTOM_BROWSER_ACTION_LABEL"
    const val ACTION_ICON_URI = "androidx.media.utils.extras.KEY_CUSTOM_BROWSER_ACTION_ICON_URI"
    const val ACTION_EXTRAS = "androidx.media.utils.extras.KEY_CUSTOM_BROWSER_ACTION_EXTRAS"
    /** Argument reçu avec l'action : l'identifiant de l'élément visé. */
    const val ACTION_MEDIA_ITEM_ID = "androidx.media.utils.extras.KEY_CUSTOM_BROWSER_ACTION_MEDIA_ITEM_ID"
    /** Résultat : message bref affiché par l'hôte. */
    const val RESULT_MESSAGE = "androidx.media.utils.extras.KEY_CUSTOM_BROWSER_ACTION_RESULT_MESSAGE"
    /** Résultat : identifiant d'un élément à recharger (le cœur change d'état). */
    const val RESULT_REFRESH_ITEM = "androidx.media.utils.extras.KEY_CUSTOM_BROWSER_ACTION_RESULT_REFRESH_ITEM"

    const val ACTION_FAVORITE = "favorite"
    const val ACTION_UNFAVORITE = "unfavorite"
    const val ACTION_PLAY_NEXT = "play_next"
    const val ACTION_ADD_TO_QUEUE = "add_to_queue"
    const val ACTION_SHUFFLE = "shuffle"

    /** Ordre de déclaration à la racine, et ordre d'affichage par l'hôte. */
    val ALL_ACTIONS: List<String> = listOf(ACTION_FAVORITE, ACTION_UNFAVORITE, ACTION_PLAY_NEXT, ACTION_ADD_TO_QUEUE, ACTION_SHUFFLE)
}
```

```kotlin
    private fun surprise(): List<Song>? {
        val random = Random(today())
        val favoriteIds = source.favorites.mapTo(HashSet()) { it.id }
        val favorites = source.favorites.shuffled(random)
        val rare = source.songs.filter { it.id !in favoriteIds && (source.playCounts[it.id] ?: 0) <= 1 }.shuffled(random)
        val picked = ArrayList<Song>(SURPRISE_SIZE)
        fun take(from: List<Song>, upTo: Int) {
            for (song in from) {
                if (picked.size >= upTo) return
                if (picked.any { it.id == song.id }) continue
                if (picked.count { it.displayArtist == song.displayArtist } >= SURPRISE_PER_ARTIST) continue
                picked += song
            }
        }
        take(favorites, SURPRISE_FAVORITES)
        take(rare, SURPRISE_SIZE)
        take(favorites, SURPRISE_SIZE)
        if (picked.size < SURPRISE_MIN) return null
```

```kotlin
    /** Action du menu contextuel de la voiture sur un élément parcouru. */
    private fun browserAction(command: SessionCommand, args: Bundle): SessionResult {
        val mediaId = args.getString(AutoKeys.ACTION_MEDIA_ITEM_ID)
            ?: command.customExtras.getString(AutoKeys.ACTION_MEDIA_ITEM_ID)
            ?: return SessionResult(androidx.media3.session.SessionError.ERROR_BAD_VALUE)
        val action = libraryTree.tree.action(command.customAction, mediaId)
            ?: return SessionResult(androidx.media3.session.SessionError.ERROR_BAD_VALUE)
        val result = Bundle().apply { putString(AutoKeys.RESULT_MESSAGE, action.message) }
        when (action) {
            is AutoAction.SetFavorite -> {
                serviceScope.launch { musicRepository.setFavorite(action.song, action.favorite) }
                result.putString(AutoKeys.RESULT_REFRESH_ITEM, mediaId)
            }
            is AutoAction.PlayNext -> insertIntoQueue(action.songs, next = true)
            is AutoAction.AddToQueue -> insertIntoQueue(action.songs, next = false)
            is AutoAction.Shuffle -> {
                activePlayer.setMediaItems(forActivePlayer(action.songs.toMediaItems()), 0, 0L)
                activePlayer.prepare()
                activePlayer.play()
            }
        }
        return SessionResult(SessionResult.RESULT_SUCCESS, result)
    }

    /** Insère après le titre courant ou en fin de file ; une file vide démarre la lecture. */
    private fun insertIntoQueue(songs: List<Song>, next: Boolean) {
        val items = forActivePlayer(songs.toMediaItems())
        if (activePlayer.mediaItemCount == 0) {
            activePlayer.setMediaItems(items, 0, 0L)
            activePlayer.prepare()
            activePlayer.play()
            return
        }
        if (next) activePlayer.addMediaItems(activePlayer.currentMediaItemIndex + 1, items)
        else activePlayer.addMediaItems(items)
    }
```

```kotlin
    /** Segments pour une pochette d'album MediaStore, ou null pour toute autre adresse. */
    fun albumArtSegments(uri: String): List<String>? {

        return if (id.isNotEmpty() && id.all { it.isDigit() }) listOf(SEGMENT_ALBUM, id) else null
```

```kotlin
package fr.synxio.player.playback.art

import android.content.Context
import android.graphics.Bitmap
import android.graphics.BitmapFactory
import android.net.Uri

/** Décodage réduit et recadrage carré, partagés par le widget, le fournisseur de pochettes et la mosaïque. */
object ArtBitmaps {

    /** Décode en réduisant avant lecture : jamais plus de deux fois [target] de côté. Null si illisible. */
    fun decode(context: Context, uri: Uri, target: Int): Bitmap? = runCatching {
        val bounds = BitmapFactory.Options().apply { inJustDecodeBounds = true }
        context.contentResolver.openInputStream(uri)?.use { BitmapFactory.decodeStream(it, null, bounds) }
        if (bounds.outWidth <= 0 || bounds.outHeight <= 0) return null
        var sample = 1
        while (minOf(bounds.outWidth, bounds.outHeight) / (sample * 2) >= target) sample *= 2
        val options = BitmapFactory.Options().apply {
            inSampleSize = sample
            inPreferredConfig = Bitmap.Config.ARGB_8888
        }
        context.contentResolver.openInputStream(uri)?.use { BitmapFactory.decodeStream(it, null, options) }
    }.getOrNull()

    /** Carré central de [src], ramené à [side] de côté s'il est plus grand. */
    fun centerCrop(src: Bitmap, side: Int): Bitmap {
        val min = minOf(src.width, src.height)
        val x = (src.width - min) / 2
        val y = (src.height - min) / 2
        val cropped = Bitmap.createBitmap(src, x, y, min, min)
        if (min <= side) return cropped
        val scaled = Bitmap.createScaledBitmap(cropped, side, side, true)
        if (cropped !== src) cropped.recycle()
        return scaled
    }
}
```

```kotlin
    private fun resolve(uri: Uri, size: Int?): File? {
        val context = context ?: return null
        val segments = uri.pathSegments
        if (segments.size != 2) return null
        val (kind, value) = segments
        val original: File? = when (kind) {

                ?.let { File(File(context.filesDir, "meta-artwork"), it) }

            ArtworkUris.SEGMENT_RADIO -> radioLogo(context.cacheDir, value)
            ArtworkUris.SEGMENT_ALBUM -> null
            else -> return null

        if (size == null) return original
        return when (kind) {
            ArtworkUris.SEGMENT_ALBUM -> value.toLongOrNull()?.let { id -> sized(context, "album/$id", size) { ArtBitmaps.decode(context, albumArtUri(id), size) } }
            else -> original?.let { file -> sized(context, "$kind/$value", size) { ArtBitmaps.decode(context, Uri.fromFile(file), size) } }
        }
    }

    /**
     * Version carrée de [size] pixels, rendue une fois puis gardée en cache par clé et
     * taille : Android Auto demande la même pochette à chaque ouverture de liste.
     */
    private fun sized(context: Context, key: String, size: Int, decode: () -> Bitmap?): File? {
        val dir = File(context.cacheDir, SIZED_CACHE_DIR).apply { mkdirs() }
        val target = File(dir, sha1("$key@$size") + ".jpg")
        if (target.isFile) return target
        val source = decode() ?: return null
        return runCatching {
            val square = ArtBitmaps.centerCrop(source, size)
            val tmp = File(dir, target.name + ".tmp")
            tmp.outputStream().use { square.compress(Bitmap.CompressFormat.JPEG, SIZED_QUALITY, it) }
            if (square !== source) square.recycle()
            source.recycle()
            if (!tmp.renameTo(target)) tmp.delete()
            target.takeIf { it.isFile }
        }.onFailure { Log.d(TAG, "Pochette redimensionnée non rendue", it) }.getOrNull()
    }
```

```kotlin
package fr.synxio.player.playback.art

import android.content.Context
import android.graphics.Bitmap
import android.graphics.Canvas
import dagger.hilt.android.qualifiers.ApplicationContext
import fr.synxio.player.data.repo.MusicRepository
import java.io.File
import java.security.MessageDigest
import javax.inject.Inject
import javax.inject.Singleton

/**
 * Mosaïque 2×2 des pochettes de quatre titres, pour les mixs, souvenirs et playlists
 * sur l'écran de la voiture. Rendue une fois par liste de titres et par taille, gardée
 * dans le cache ; les mixs changeant chaque jour, les fichiers de plus d'une semaine
 * sont balayés à chaque nouveau rendu.
 */
@Singleton
class MosaicRenderer @Inject constructor(
    @ApplicationContext private val context: Context,
    private val music: MusicRepository,
) {

    fun render(songIds: List<Long>, side: Int): File? {
        val dir = File(context.cacheDir, DIR).apply { mkdirs() }
        val target = File(dir, sha1(songIds.joinToString(",") + "@" + side) + ".jpg")
        if (target.isFile) return target

        val half = side / 2
        val tiles = songIds.mapNotNull { music.songById(it)?.artworkUri }
            .mapNotNull { ArtBitmaps.decode(context, it, half) }
        if (tiles.isEmpty()) return null

        return runCatching {
            val out = Bitmap.createBitmap(side, side, Bitmap.Config.ARGB_8888)
            val canvas = Canvas(out)
            for (i in 0 until 4) {
                // Moins de quatre pochettes : on répète dans l'ordre.
                val square = ArtBitmaps.centerCrop(tiles[i % tiles.size], half)
                canvas.drawBitmap(square, ((i % 2) * half).toFloat(), ((i / 2) * half).toFloat(), null)
            }
            tiles.forEach { it.recycle() }
            val tmp = File(dir, target.name + ".tmp")
            tmp.outputStream().use { out.compress(Bitmap.CompressFormat.JPEG, QUALITY, it) }
            out.recycle()
            if (!tmp.renameTo(target)) tmp.delete()
            sweep(dir, keep = target.name)
            target.takeIf { it.isFile }
        }.getOrNull()
    }

    private fun sweep(dir: File, keep: String) {
        val cutoff = System.currentTimeMillis() - MAX_AGE_MS
        dir.listFiles()?.forEach { if (it.name != keep && it.lastModified() < cutoff) it.delete() }
    }

    private fun sha1(value: String): String =
        MessageDigest.getInstance("SHA-1").digest(value.toByteArray()).joinToString("") { "%02x".format(it) }

    private companion object {
        const val DIR = "auto-mosaic"
        const val QUALITY = 88
        const val MAX_AGE_MS = 7L * 24 * 3600 * 1000
    }
}
```
