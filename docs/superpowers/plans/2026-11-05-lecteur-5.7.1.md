**Goal:** Livrer la 5.7.1 : position de lecture dans un flux séparé (plus de recomposition racine à 4 Hz), lecteur plein écran qui suit le doigt et le retour prédictif, mini-lecteur avec balayage de fermeture, retour haptique cohérent et débrayable.

**Architecture:** Trois chantiers dans l'ordre I6 → P7 → I10. Chacun a un cœur pur testé sur la JVM (`PlayerPosition`, `SynxioHaptics`, `PlayerSheetState`) et une enveloppe Compose. `SynxioRoot` reste le seul propriétaire de l'état d'expansion du lecteur ; `MiniPlayer` et `NowPlayingScreen` ne font que remonter des déplacements et des vélocités.

**Tech Stack:** Kotlin 2.4, Compose BOM 2026.09 (Material3, `HapticFeedbackType`, `VelocityTracker`), activity-compose 1.13 (`PredictiveBackHandler`), Hilt, DataStore Preferences, JUnit 4 sur la JVM.

**Spec:** `docs/superpowers/specs/2026-11-05-lecteur-5.7.1-design.md`

## Global Constraints

- Aucune nouvelle dépendance Gradle.
- Textes de l'interface en français, tutoiement. KDoc et commentaires en français, pas de TODO.
- `runCatching` toujours suivi d'un `diagnostics.log(...)` dans les zones touchées.
- Cadence d'échantillonnage de la position inchangée : 250 ms en lecture, 1 000 ms en pause, `LOOP_TICK_MS` en boucle A-B.
- `PlayerUiState` ne porte plus `positionMs`, `bufferedMs` ni `progress` ; il garde `durationMs`.
- `AnimatedVisibility` du lecteur plein écran conservé (pochette partagée), transitions `EnterTransition.None` / `ExitTransition.None`, mouvement par `graphicsLayer` piloté par `expansion`.
- Seuils des gestes : `OPEN_THRESHOLD = 0.3f`, `FLING_VELOCITY = 1_200f` px/s, `DRAG_ZONE = 0.65f`, fermeture du mini-lecteur à 40 % de sa hauteur.
- Haptique uniquement via `LocalHapticFeedback` (pas de permission `VIBRATE`) ; `tap` → `VirtualKey`, `confirm` → `Confirm`, `tick` → `SegmentTick`, `release` → `GestureEnd`.
- Réglage « Retour haptique » : `Settings.hapticsEnabled` (défaut `true`), clé `haptics_enabled`, groupe « Mouvement et lumière ».
- Animations réduites (`LocalReduceMotion`) : pas de suivi continu, fondu simple, décision au relâcher.
- Commandes Gradle lancées depuis PowerShell (`.\gradlew.bat`), jamais depuis Git Bash. Tests JVM : `.\gradlew.bat :app:testDebugUnitTest --tests "<classe>"`.
- Chaque tâche se termine par un commit sur `dev-5.5`. Pas de push.

```kotlin
package fr.synxio.player.ui.haptics

import androidx.compose.runtime.Composable
import androidx.compose.runtime.remember
import androidx.compose.runtime.staticCompositionLocalOf
import androidx.compose.ui.hapticfeedback.HapticFeedback
import androidx.compose.ui.hapticfeedback.HapticFeedbackType
import androidx.compose.ui.platform.LocalHapticFeedback

/**
 * Vocabulaire haptique de Synxio : quatre intentions, pas des types système.
 *
 * Les écrans parlent en intentions (« un tap », « une confirmation ») ; la correspondance
 * avec les types Compose vit ici, et le réglage « Retour haptique » choisit entre
 * [ComposeHaptics] et [None] sans que les écrans le sachent.
 */
interface SynxioHaptics {
    /** Commande simple : lecture/pause, changement d'onglet. */
    fun tap()
    /** Action qui laisse une trace : cœur, ajout à la file, signet. */
    fun confirm()
    /** Cran franchi : changement de piste par balayage, seuil d'un geste. */
    fun tick()
    /** Fin d'un glissement : relâcher de la barre de progression. */
    fun release()

    /** Silence : réglage désactivé ou aperçu. */
    object None : SynxioHaptics {
        override fun tap() = Unit
        override fun confirm() = Unit
        override fun tick() = Unit
        override fun release() = Unit
    }
}

/** Haptique réelle, via [HapticFeedback] de Compose (respecte le réglage système). */
class ComposeHaptics(private val feedback: HapticFeedback) : SynxioHaptics {
    override fun tap() = feedback.performHapticFeedback(HapticFeedbackType.VirtualKey)
    override fun confirm() = feedback.performHapticFeedback(HapticFeedbackType.Confirm)
    override fun tick() = feedback.performHapticFeedback(HapticFeedbackType.SegmentTick)
    override fun release() = feedback.performHapticFeedback(HapticFeedbackType.GestureEnd)
}

val LocalSynxioHaptics = staticCompositionLocalOf<SynxioHaptics> { SynxioHaptics.None }

/** À fournir une fois à la racine, selon `Settings.hapticsEnabled`. */
@Composable
fun rememberSynxioHaptics(enabled: Boolean): SynxioHaptics {
    val feedback = LocalHapticFeedback.current
    return remember(enabled, feedback) { if (enabled) ComposeHaptics(feedback) else SynxioHaptics.None }
}
```

```kotlin
package fr.synxio.player.ui.components

/**
 * Décisions des gestes d'ouverture et de fermeture du lecteur, sans Compose.
 *
 * L'expansion va de 0 (mini-lecteur) à 1 (plein écran). Un déplacement positif va vers
 * le bas et ferme ; négatif, il ouvre. Les seuils sont ceux de la spécification 5.7.1.
 */
class PlayerSheetState(private val screenHeightPx: Float) {

    /** Expansion atteinte après un déplacement cumulé [dragPx] depuis [startExpansion]. */
    fun dragTo(startExpansion: Float, dragPx: Float): Float =
        (startExpansion - dragPx / screenHeightPx).coerceIn(0f, 1f)

    /**
     * Cible au relâcher : 1f ouvre, 0f ferme.
     *
     * Une vélocité franche décide seule ; sinon il faut avoir parcouru 30 % depuis le
     * point de départ, pour qu'un geste hésitant revienne d'où il vient.
     */
    fun settle(startExpansion: Float, expansion: Float, velocityPxPerSec: Float): Float = when {
        velocityPxPerSec >= FLING_VELOCITY -> 0f
        velocityPxPerSec <= -FLING_VELOCITY -> 1f
        startExpansion <= 0.5f -> if (expansion >= OPEN_THRESHOLD) 1f else 0f
        else -> if (expansion <= 1f - OPEN_THRESHOLD) 0f else 1f
    }

    /** Le balayage de fermeture ne part que du haut de l'écran : jamais des commandes. */
    fun canStartDrag(startYFraction: Float): Boolean = startYFraction <= DRAG_ZONE

    companion object {
        const val OPEN_THRESHOLD = 0.3f
        const val FLING_VELOCITY = 1_200f
        const val DRAG_ZONE = 0.65f
    }
}
```

```kotlin
/**
 * Balayage vers le bas qui referme le lecteur en suivant le doigt.
 *
 * Le geste ne part que du haut de l'écran ([PlayerSheetState.canStartDrag]) ; une liste
 * qui peut encore défiler consomme le déplacement avant nous. Un `tick` haptique signale
 * le franchissement du seuil de fermeture, une fois par geste.
 */
private fun Modifier.playerDismissGesture(
    sheet: PlayerSheetState,
    expansion: Animatable<Float, AnimationVector1D>,
    scope: CoroutineScope,
    haptics: SynxioHaptics,
    reduceMotion: Boolean,
): Modifier = pointerInput(sheet, reduceMotion) {
    val tracker = VelocityTracker()
    var allowed = false
    var start = 1f
    var total = 0f
    var ticked = false
    detectVerticalDragGestures(
        onDragStart = { offset ->
            allowed = sheet.canStartDrag(offset.y / size.height)
            start = expansion.value
            total = 0f
            ticked = false
            tracker.resetTracking()
        },
        onDragEnd = {
            if (!allowed) return@detectVerticalDragGestures
            val velocity = tracker.calculateVelocity().y
            val target = if (reduceMotion) {
                if (total > size.height * PlayerSheetState.OPEN_THRESHOLD || velocity >= PlayerSheetState.FLING_VELOCITY) 0f else 1f
            } else {
                sheet.settle(start, expansion.value, velocity)
            }
            scope.launch { expansion.animateTo(target, if (reduceMotion) Motion.standard(Motion.SHORT) else Motion.spatial()) }
        },
        onDragCancel = { scope.launch { expansion.animateTo(1f, Motion.spatial()) } },
    ) { change, dragAmount ->
        if (!allowed) return@detectVerticalDragGestures
        change.consume()
        total += dragAmount
        tracker.addPosition(change.uptimeMillis, change.position)
        if (!reduceMotion) {
            val next = sheet.dragTo(start, total)
            if (!ticked && next <= 1f - PlayerSheetState.OPEN_THRESHOLD) { ticked = true; haptics.tick() }
            scope.launch { expansion.snapTo(next) }
        }
    }
}
```
