# Au poignet 5.10.0 — plan 2 : application montre

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une application Wear OS `:wear` qui affiche la lecture du téléphone, la pilote (lecture/pause, précédent/suivant, cœur, volume à la couronne, lancement rapide), et la prolonge par une tuile et une complication « en cours ».

**Architecture:** `WearStateStore` (fichiers + `StateFlow`) est la seule source de vérité sur la montre : il est rempli par `WearStateListener` (`WearableListenerService`, événement `DATA_CHANGED` sur `/synxio/state`) et, au démarrage, par une relecture du `DataItem` courant. `PhoneLink` sait si un téléphone porte la capacité `synxio_phone` et envoie les messages `/synxio/cmd`. `PlayerViewModel` combine store et lien en un `PlayerUiState` (déconnecté, vide, connexion, lecture) avec bascules optimistes ; trois écrans Compose Wear M3 le dessinent. La tuile et la complication lisent le store de façon synchrone et sont rafraîchies par le listener.

**Tech Stack:** Compose for Wear OS Material 3 1.7.2 (`compose-material3`, `compose-foundation`, `compose-navigation`), Tiles 1.6.2 + ProtoLayout 1.4.2 (`protolayout-material3`), `watchface-complications-data-source-ktx` 1.3.0, `androidx.wear:wear` 1.4.0 (ambiant), `play-services-wearable` 20.0.1, Hilt 2.60.1, `:wear-protocol` (plan 1), JUnit 4, `kotlinx-coroutines-test`.

**Spec:** `docs/superpowers/specs/2026-11-19-wear-os-5.10.0-design.md` (sections 1.3, 2, 3)

**Prérequis :** plan 1 (`2026-11-19-au-poignet-5.10.0-telephone.md`) exécuté : `:wear-protocol` existe, `gradle.properties` porte `synxio.versionCode` / `synxio.versionName`.

## Global Constraints

- `applicationId = "fr.synxio.player"` (debug : suffixe `.debug`, comme `:app`) : le Data Layer ne relie que des applications de même identifiant et même signature. `namespace = "fr.synxio.player.watch"`. `minSdk 30`, `targetSdk 34`, `compileSdk 37` / `compileSdkMinor 2` comme `:app`.
- Version lue depuis `gradle.properties` (`synxio.versionCode`, `synxio.versionName`), identique à `:app`.
- Signature release : même bloc `signingConfigs` que `app/build.gradle.kts` (dupliqué, voir plan 1 « Global Constraints »).
- Fond encre `#0C0A10` partout ; accent = `WearState.accent`, repli braise `#FF6A3D` si `0`. Police système.
- Textes : « Synxio est en pause sur le téléphone », « Téléphone hors de portée », « Téléphone injoignable », « Play Services requis », « Mets à jour Synxio sur le téléphone », « Mets à jour Synxio sur la montre », « Connexion… », « Reprendre », « Favoris », « Aléatoire », « Surprends-moi ». Tutoiement, français.
- Délais : bascule optimiste 3 s ; attente après `Start` 8 s ; indicateur de volume visible 1,5 s ; rafale couronne 80 ms ; pas de volume absolu depuis l'UI.
- Pas de polling : tuile `freshnessIntervalMillis = 0`, complication `UPDATE_PERIOD_SECONDS = 0`, toutes deux rafraîchies par `WearStateListener`.
- ProtoLayout Material 3 seulement (`androidx.wear.protolayout.material3`), jamais `tiles-material` (M2). Si une signature diffère dans 1.4.2, s'aligner sur la javadoc de cette version.
- KDoc et commentaires en français, pas de TODO.

package fr.synxio.player.watch.data

import fr.synxio.player.wear.protocol.WearState
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import java.io.File

/** Dernier état reçu du téléphone et ses images ; `state == null` tant que rien n'est arrivé. */
data class StoredState(
    val state: WearState?,
    val art: ByteArray?,
    val artBlurred: ByteArray?,
)

/**
 * Source de vérité de la montre.
 *
 * Rempli par `WearStateListener` (même si l'appli est fermée) et relu par l'interface,
 * la tuile et la complication, qui ne touchent jamais au Data Layer elles-mêmes.
 * Persisté en fichiers : un processus tout juste créé pour dessiner la tuile retrouve
 * l'état sans attendre Play Services.
 */
class WearStateStore(private val dir: File) {

    private val _stored = MutableStateFlow(StoredState(null, null, null))
    val stored: StateFlow<StoredState> = _stored.asStateFlow()

    private val stateFile get() = File(dir, "state.json")
    private val artFile get() = File(dir, "art.jpg")
    private val blurredFile get() = File(dir, "art_blurred.jpg")

    @Synchronized
    fun load() {
        val state = stateFile.takeIf { it.exists() }?.readText()?.let(WearState::fromJson)
        _stored.value = StoredState(
            state = state,
            art = artFile.takeIf { state != null && it.exists() }?.readBytes(),
            artBlurred = blurredFile.takeIf { state != null && it.exists() }?.readBytes(),
        )
    }

    /**
     * Enregistre [state]. Images `null` : conservées si le titre n'a pas changé (le
     * téléphone ne les renvoie pas à chaque transition), effacées sinon.
     */
    @Synchronized
    fun save(state: WearState, art: ByteArray?, artBlurred: ByteArray?) {
        dir.mkdirs()
        val previous = _stored.value
        val sameTrack = !state.isEmpty && previous.state?.mediaId == state.mediaId
        val keptArt = art ?: previous.art?.takeIf { sameTrack }
        val keptBlurred = artBlurred ?: previous.artBlurred?.takeIf { sameTrack }

        stateFile.writeText(state.toJson())
        if (keptArt != null) artFile.writeBytes(keptArt) else artFile.delete()
        if (keptBlurred != null) blurredFile.writeBytes(keptBlurred) else blurredFile.delete()
        _stored.value = StoredState(state, keptArt, keptBlurred)
    }

    fun current(): StoredState = _stored.value
}

```kotlin
package fr.synxio.player.watch.data

import android.content.Context
import android.net.Uri
import android.util.Log
import com.google.android.gms.wearable.Asset
import com.google.android.gms.wearable.DataClient
import com.google.android.gms.wearable.DataItem
import com.google.android.gms.wearable.DataMapItem
import com.google.android.gms.wearable.Wearable
import fr.synxio.player.wear.protocol.WearPaths
import fr.synxio.player.wear.protocol.WearState
import kotlinx.coroutines.tasks.await

/**
 * Traduit le `DataItem` `/synxio/state` en [WearStateStore].
 *
 * Les `Asset` ne sont lus que lorsque le titre change : le téléphone les réattache à
 * chaque publication, mais leurs octets sont déjà dans le store.
 */
class DataLayerStateReader(
    private val context: Context,
    private val store: WearStateStore,
) {
    private val dataClient: DataClient get() = Wearable.getDataClient(context)

    suspend fun apply(item: DataItem) {
        if (item.uri.path != WearPaths.STATE) return
        val map = DataMapItem.fromDataItem(item).dataMap
        val state = map.getString(WearPaths.KEY_STATE)?.let(WearState::fromJson) ?: return
        val needArt = !state.isEmpty && (store.current().state?.mediaId != state.mediaId || store.current().art == null)
        val art = if (needArt) map.getAsset(WearPaths.KEY_ART)?.let { read(it) } else null
        val blurred = if (needArt) map.getAsset(WearPaths.KEY_ART_BLURRED)?.let { read(it) } else null
        store.save(state, art, blurred)
    }

    /** Relit le `DataItem` courant (démarrage de l'appli, listener manqué). */
    suspend fun refreshFromDataLayer() {
        try {
            val buffer = dataClient.getDataItems(Uri.parse("wear://*${WearPaths.STATE}"), DataClient.FILTER_LITERAL).await()
            try {
                // Un seul téléphone appairé : le dernier item publié gagne.
                buffer.lastOrNull()?.let { apply(it) }
            } finally {
                buffer.release()
            }
        } catch (e: Exception) {
            Log.w(TAG, "État du téléphone illisible", e)
        }
    }

    private suspend fun read(asset: Asset): ByteArray? = try {
        dataClient.getFdForAsset(asset).await().inputStream.use { it.readBytes() }
    } catch (e: Exception) {
        Log.w(TAG, "Pochette illisible", e)
        null
    }

    private companion object {
        const val TAG = "SynxioWear"
    }
}

package fr.synxio.player.watch.data

import com.google.android.gms.wearable.DataEvent
import com.google.android.gms.wearable.DataEventBuffer
import com.google.android.gms.wearable.WearableListenerService
import dagger.hilt.android.AndroidEntryPoint
import kotlinx.coroutines.runBlocking
import javax.inject.Inject

/**
 * Reçoit chaque nouvel état du téléphone, même appli fermée, et le range dans le store.
 *
 * `onDataChanged` tourne sur un thread de Play Services : la lecture des `Asset` y est
 * bloquante par conception (le service est libéré au retour).
 */
@AndroidEntryPoint
class WearStateListener : WearableListenerService() {

    @Inject lateinit var store: WearStateStore

    override fun onDataChanged(events: DataEventBuffer) {
        val reader = DataLayerStateReader(this, store)
        var changed = false
        for (event in events) {
            if (event.type != DataEvent.TYPE_CHANGED) continue
            runBlocking { reader.apply(event.dataItem) }
            changed = true
        }
        if (changed) WearSurfaces.refreshAll(this)
    }
}

package fr.synxio.player.watch.data

import android.content.Context
import android.util.Log
import com.google.android.gms.common.ConnectionResult
import com.google.android.gms.common.GoogleApiAvailability
import com.google.android.gms.wearable.CapabilityClient
import com.google.android.gms.wearable.CapabilityInfo
import com.google.android.gms.wearable.Wearable
import fr.synxio.player.wear.protocol.WearCommand
import fr.synxio.player.wear.protocol.WearPaths
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.tasks.await

enum class Connectivity { UNKNOWN, PHONE_REACHABLE, PHONE_UNREACHABLE, PLAY_SERVICES_MISSING }

/** Le téléphone vu de la montre : est-il joignable, et comment lui parler. */
interface PhoneLink {
    val connectivity: StateFlow<Connectivity>
    /** Relit la capacité et le `DataItem` courant. À appeler au premier plan. */
    suspend fun refresh()
    suspend fun send(command: WearCommand): Result<Unit>
}

class DataLayerPhoneLink(
    private val context: Context,
    private val reader: DataLayerStateReader,
) : PhoneLink {

    private val _connectivity = MutableStateFlow(Connectivity.UNKNOWN)
    override val connectivity: StateFlow<Connectivity> = _connectivity.asStateFlow()

    private var phoneNodeId: String? = null
    private var listening = false

    private val capabilityListener = CapabilityClient.OnCapabilityChangedListener { info -> update(info) }

    override suspend fun refresh() {
        if (GoogleApiAvailability.getInstance().isGooglePlayServicesAvailable(context) != ConnectionResult.SUCCESS) {
            _connectivity.value = Connectivity.PLAY_SERVICES_MISSING
            return
        }
        try {
            val client = Wearable.getCapabilityClient(context)
            update(client.getCapability(WearPaths.CAPABILITY_PHONE, CapabilityClient.FILTER_REACHABLE).await())
            if (!listening) {
                client.addListener(capabilityListener, WearPaths.CAPABILITY_PHONE)
                listening = true
            }
        } catch (e: Exception) {
            Log.w(TAG, "Capacité du téléphone illisible", e)
            _connectivity.value = Connectivity.PHONE_UNREACHABLE
        }
        reader.refreshFromDataLayer()
    }

    private fun update(info: CapabilityInfo) {
        val node = info.nodes.firstOrNull { it.isNearby } ?: info.nodes.firstOrNull()
        phoneNodeId = node?.id
        _connectivity.value = if (node != null) Connectivity.PHONE_REACHABLE else Connectivity.PHONE_UNREACHABLE
    }

    override suspend fun send(command: WearCommand): Result<Unit> {
        val node = phoneNodeId ?: return Result.failure(IllegalStateException("Aucun téléphone joignable"))
        return runCatching {
            Wearable.getMessageClient(context)
                .sendMessage(node, WearPaths.COMMAND, command.encode().toByteArray(Charsets.UTF_8))
                .await()
            Unit
        }.onFailure { Log.w(TAG, "Commande non envoyée : $command", it) }
    }

    private companion object {
        const val TAG = "SynxioWear"
    }
}

import kotlinx.coroutines.launch
import javax.inject.Inject
import kotlin.math.sign

/**
 * État de l'écran lecteur.
 *
 * Les commandes partent tout de suite et l'écran bascule sans attendre ; le prochain état
 * du téléphone (ou [OPTIMISM_MS]) remet les compteurs. Les crans de couronne sont
 * groupés par [CROWN_WINDOW_MS] : un pas envoyé par rafale, jamais une pluie de messages.
 */
@HiltViewModel
class PlayerViewModel(
    private val store: WearStateStore,
    private val link: PhoneLink,
    private val clock: () -> Long,
) : ViewModel() {

    @Inject constructor(store: WearStateStore, link: PhoneLink) : this(store, link, System::currentTimeMillis)

    /** Bascules locales en attente de confirmation. */
    private data class Pending(
        val playing: Boolean? = null,
        val favorite: Boolean? = null,
        val volume: Float? = null,
        val volumeVisible: Boolean = false,
        val connectingSince: Long? = null,
    )

    private val pending = MutableStateFlow(Pending())
    private var optimismJob: Job? = null
    private var volumeHideJob: Job? = null
    private var connectingJob: Job? = null
    private var crownJob: Job? = null
    private var crownSteps = 0

    private val _events = MutableSharedFlow<String>(extraBufferCapacity = 4)
    val events: SharedFlow<String> = _events.asSharedFlow()

    val art: StateFlow<ByteArray?> = store.stored.map { it.art }
        .stateIn(viewModelScope, SharingStarted.Eagerly, store.current().art)
    val artBlurred: StateFlow<ByteArray?> = store.stored.map { it.artBlurred }
        .stateIn(viewModelScope, SharingStarted.Eagerly, store.current().artBlurred)

    val uiState: StateFlow<PlayerUiState> = combine(store.stored, link.connectivity, pending) { stored, connectivity, p ->
        build(stored.state, connectivity, p)
    }.stateIn(viewModelScope, SharingStarted.Eagerly, PlayerUiState.Idle)

    init {
        // Tout nouvel état du téléphone clôt l'optimisme et la connexion en cours.
        viewModelScope.launch {
            var last = store.current().state
            store.stored.collect { stored ->
                if (stored.state != last) {
                    last = stored.state
                    optimismJob?.cancel()
                    val connecting = pending.value.connectingSince
                    val arrived = stored.state?.let { !it.isEmpty && connecting != null && it.capturedAtMs >= connecting } == true
                    pending.update {
                        it.copy(
                            playing = null, favorite = null, volume = null,
                            connectingSince = if (arrived) null else it.connectingSince,
                        )
                    }
                    if (arrived) connectingJob?.cancel()
                }
            }
        }
    }

    private fun build(state: WearState?, connectivity: Connectivity, p: Pending): PlayerUiState {
        when (connectivity) {
            Connectivity.PLAY_SERVICES_MISSING -> return PlayerUiState.PlayServicesMissing
            Connectivity.PHONE_UNREACHABLE -> return PlayerUiState.PhoneUnreachable
            Connectivity.UNKNOWN, Connectivity.PHONE_REACHABLE -> Unit
        }
        if (p.connectingSince != null) return PlayerUiState.Connecting
        if (state == null || state.isEmpty) return PlayerUiState.Idle
        if (state.protocolVersion != WearPaths.PROTOCOL_VERSION) {
            return PlayerUiState.VersionMismatch(phoneNewer = state.protocolVersion > WearPaths.PROTOCOL_VERSION)
        }
        val now = clock()
        return PlayerUiState.Playing(
            state = state,
            isPlaying = p.playing ?: (state.isPlaying && !state.isStaleAt(now)),
            favorite = p.favorite ?: state.favorite,
            volume = p.volume ?: state.volume,
            volumeVisible = p.volumeVisible,
        )
    }

    fun onForeground() {
        viewModelScope.launch { link.refresh() }
    }

    fun playPause() {
        val current = uiState.value as? PlayerUiState.Playing
        if (current != null) optimistic { it.copy(playing = !current.isPlaying) }
        send(WearCommand.PlayPause)
    }

    fun next() = send(WearCommand.Next)
    fun previous() = send(WearCommand.Previous)

    fun toggleFavorite() {
        val current = uiState.value as? PlayerUiState.Playing ?: return
        optimistic { it.copy(favorite = !current.favorite) }
        send(WearCommand.ToggleFavorite)
    }

    /** Un cran de couronne : +1 ou -1. */
    fun volumeStep(delta: Int) {
        crownSteps += delta
        if (crownJob?.isActive == true) return
        crownJob = viewModelScope.launch {
            delay(CROWN_WINDOW_MS)
            val net = crownSteps.sign
            crownSteps = 0
            if (net == 0) return@launch
            val current = uiState.value as? PlayerUiState.Playing
            if (current != null) {
                val level = (current.volume + net * VOLUME_STEP).coerceIn(0f, 1f)
                optimistic { it.copy(volume = level, volumeVisible = true) }
                volumeHideJob?.cancel()
                volumeHideJob = viewModelScope.launch {
                    delay(VOLUME_VISIBLE_MS)
                    pending.update { it.copy(volumeVisible = false) }
                }
            }
            send(if (net > 0) WearCommand.VolumeUp else WearCommand.VolumeDown)
        }
    }

    fun start(mediaId: String) {
        val since = clock()
        pending.update { it.copy(connectingSince = since) }
        connectingJob?.cancel()
        connectingJob = viewModelScope.launch {
            delay(CONNECT_TIMEOUT_MS)
            if (pending.value.connectingSince == since) {
                pending.update { it.copy(connectingSince = null) }
                _events.tryEmit(UNREACHABLE)
            }
        }
        send(WearCommand.Start(mediaId))
    }

    private fun optimistic(change: (Pending) -> Pending) {
        pending.update(change)
        optimismJob?.cancel()
        optimismJob = viewModelScope.launch {
            delay(OPTIMISM_MS)
            pending.update { it.copy(playing = null, favorite = null, volume = null) }
        }
    }

    private fun send(command: WearCommand) {
        viewModelScope.launch {
            link.send(command).onFailure {
                pending.update { it.copy(playing = null, favorite = null, volume = null, connectingSince = null) }
                connectingJob?.cancel()
                _events.tryEmit(UNREACHABLE)
            }
        }
    }

    private companion object {
        const val OPTIMISM_MS = 3_000L
        const val CONNECT_TIMEOUT_MS = 8_000L
        const val VOLUME_VISIBLE_MS = 1_500L
        const val CROWN_WINDOW_MS = 80L
        const val VOLUME_STEP = 1f / 15f
        const val UNREACHABLE = "Téléphone injoignable"
    }
}

import androidx.compose.foundation.gestures.detectHorizontalDragGestures
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.ui.Modifier
import androidx.compose.ui.input.pointer.pointerInput

/** Couche transparente qui détecte un glissé vers la gauche et pousse la route « Lancer ». */
@Composable
private fun HorizontalSwipeToLaunch(nav: NavHostController) {
    Box(
        Modifier
            .fillMaxSize()
            .pointerInput(Unit) {
                var total = 0f
                detectHorizontalDragGestures(
                    onDragStart = { total = 0f },
                    onHorizontalDrag = { _, dragAmount -> total += dragAmount },
                    onDragEnd = {
                        if (total < -SWIPE_THRESHOLD_PX && nav.currentDestination?.route == ROUTE_PLAYER) nav.navigate(ROUTE_LAUNCH)
                    },
                )
            },
    )
}

private const val SWIPE_THRESHOLD_PX = 120f

Cette couche ne doit pas intercepter les touchers des boutons : la placer AVANT `WatchTheme { … }` dans l'arbre revient à la mettre en dessous (ordre de dessin = ordre de déclaration dans un `Box` parent). Envelopper donc le contenu de `WatchNav` dans un `Box { HorizontalSwipeToLaunch(nav); WatchTheme { … } }` : la couche de geste est en dessous, les boutons au-dessus consomment leurs touchers, et le glissé sur une zone vide atteint la couche. @AndroidEntryPoint
class SynxioTileService : TileService() {

    @Inject lateinit var store: WearStateStore
    @Inject lateinit var link: PhoneLink

    private val scope = CoroutineScope(SupervisorJob() + Dispatchers.Main)

    override fun onTileRequest(requestParams: RequestBuilders.TileRequest): ListenableFuture<TileBuilders.Tile> {
        val clicked = requestParams.currentState.lastClickableId
        val state = store.current().state ?: WearState()
        val shown = when (clicked) {
            ID_PLAY_PAUSE -> { send(WearCommand.PlayPause); state.copy(isPlaying = !state.isPlaying) }
            ID_NEXT -> { send(WearCommand.Next); state }
            ID_HEART -> { send(WearCommand.ToggleFavorite); state.copy(favorite = !state.favorite) }
            ID_RESUME -> { send(WearCommand.Start(WearStartIds.LAST_QUEUE)); state }
            ID_FAVORITES -> { send(WearCommand.Start(WearStartIds.FAVORITES)); state }
            else -> state
        }
        val layout = materialScope(this, requestParams.deviceConfiguration) {
            if (shown.isEmpty) idleLayout() else playingLayout(shown)
        }
        val tile = TileBuilders.Tile.Builder()
            .setResourcesVersion(resourcesVersion(shown))
            .setFreshnessIntervalMillis(0)
            .setTileTimeline(Timeline.fromLayoutElement(layout))
            .build()
        return CallbackToFutureAdapter.getFuture { completer -> completer.set(tile); "tile" }
    }

    override fun onTileResourcesRequest(requestParams: RequestBuilders.ResourcesRequest): ListenableFuture<ResourceBuilders.Resources> {
        val builder = ResourceBuilders.Resources.Builder()
            .setVersion(requestParams.version)
            .addIdToImageMapping(RES_PLAY, drawable(R.drawable.ic_tile_play))
            .addIdToImageMapping(RES_PAUSE, drawable(R.drawable.ic_tile_pause))
            .addIdToImageMapping(RES_NEXT, drawable(R.drawable.ic_tile_next))
            .addIdToImageMapping(RES_HEART, drawable(R.drawable.ic_tile_heart))
            .addIdToImageMapping(RES_HEART_OUTLINE, drawable(R.drawable.ic_tile_heart_outline))
            .addIdToImageMapping(RES_NOTE, drawable(R.drawable.ic_tile_note))
        store.current().art?.let { bytes ->
            builder.addIdToImageMapping(
                RES_ART,
                ResourceBuilders.ImageResource.Builder()
                    .setInlineResource(
                        ResourceBuilders.InlineImageResource.Builder()
                            .setData(bytes)
                            .setWidthPx(WearPaths.ART_PIXELS)
                            .setHeightPx(WearPaths.ART_PIXELS)
                            .setFormat(ResourceBuilders.IMAGE_FORMAT_UNDEFINED)
                            .build(),
                    )
                    .build(),
            )
        }
        val resources = builder.build()
        return CallbackToFutureAdapter.getFuture { completer -> completer.set(resources); "resources" }
    }

    override fun onDestroy() {
        scope.cancel()
        super.onDestroy()
    }

@AndroidEntryPoint
class NowPlayingComplicationService : SuspendingComplicationDataSourceService() {

    @Inject lateinit var store: WearStateStore

    override fun getPreviewData(type: ComplicationType): ComplicationData? =
        build(type, WearState(mediaId = "preview", title = "Clair de lune", artist = "Debussy"), art = null)

    override suspend fun onComplicationRequest(request: ComplicationRequest): ComplicationData? {
        val stored = store.current()
        return build(request.complicationType, stored.state ?: WearState(), stored.art)
    }

    private fun build(type: ComplicationType, state: WearState, art: ByteArray?): ComplicationData? {
        val tap = tapAction()
        val title = if (state.isEmpty) getString(R.string.app_name) else state.title
        val description = PlainComplicationText.Builder(title).build()
        val note = MonochromaticImage.Builder(Icon.createWithResource(this, R.drawable.ic_tile_note)).build()
        return when (type) {
            ComplicationType.SHORT_TEXT -> ShortTextComplicationData.Builder(
                PlainComplicationText.Builder(title.take(SHORT_MAX)).build(), description,
            ).setMonochromaticImage(note).setTapAction(tap).build()

            ComplicationType.LONG_TEXT -> LongTextComplicationData.Builder(
                PlainComplicationText.Builder(if (state.isEmpty) title else "${state.title} — ${state.artist}").build(),
                description,
            ).setMonochromaticImage(note).setTapAction(tap).build()

            ComplicationType.SMALL_IMAGE -> {
                val bitmap = art?.let { BitmapFactory.decodeByteArray(it, 0, it.size) }
                val image = if (bitmap != null) {
                    SmallImage.Builder(Icon.createWithBitmap(bitmap), SmallImageType.PHOTO).build()
                } else {
                    SmallImage.Builder(Icon.createWithResource(this, R.drawable.ic_launcher_foreground), SmallImageType.ICON).build()
                }
                SmallImageComplicationData.Builder(image, description).setTapAction(tap).build()
            }

            else -> null
        }
    }

    private fun tapAction(): PendingIntent = PendingIntent.getActivity(
        this, 0, Intent(this, MainActivity::class.java),
        PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE,
    )

    companion object {
        private const val SHORT_MAX = 7

        /** Pour `WearSurfaces` : redemande toutes les complications de cette source. */
        fun requestUpdate(context: Context) {
            ComplicationDataSourceUpdateRequester
                .create(context, ComponentName(context, NowPlayingComplicationService::class.java))
                .requestUpdateAll()
        }
    }

```markdown
### Montre (Wear OS)

Synxio pilote la lecture du téléphone depuis une montre Wear OS (testé sur Galaxy Watch 7) :
lecture/pause, précédent/suivant, cœur, volume à la couronne, lancement des favoris, de la
lecture aléatoire, de la reprise ou de « Surprends-moi », plus une tuile et une complication
« en cours ». La montre ne stocke aucune musique : c'est une télécommande.

**Installation** (l'APK montre n'est pas sur le Play Store) :

1. Sur la montre : *Paramètres → À propos de la montre → Logiciel*, sept appuis sur
   *Version du logiciel*. Puis *Options de développeur* : activer *Débogage ADB* et
   *Débogage via Wi-Fi*. La montre affiche son adresse IP.
2. Sur le PC, montre et PC sur le même Wi-Fi :
   ```powershell
   adb connect <ip-montre>:5555
   adb -s <ip-montre>:5555 install -r synxio-player-wear-vX.Y.Z.apk
   ```
   Accepter l'invite de débogage sur la montre.
3. Installer la même version de `synxio-player-vX.Y.Z.apk` sur le téléphone. Versions
   différentes : la montre demande une mise à jour.

Prérequis : services Google Play sur le téléphone et la montre (c'est déjà le cas si la
montre est appairée par Galaxy Wearable ou Wear OS).
```

## Synxio Player 5.10.0 — Au poignet

### Nouveautés
- **Synxio sur ta montre Wear OS** : ce qui joue, lecture/pause, précédent/suivant, le cœur,
  et le volume à la couronne. Depuis « Lancer » : Reprendre, Favoris, Aléatoire,
  Surprends-moi, sans toucher le téléphone.
- **Tuile « en cours »** : titre, artiste, lecture/pause · suivant · cœur, à un balayage du
  cadran. Sans lecture, Reprendre et Favoris.
- **Complication « en cours »** : le titre ou la pochette sur ton cadran, un appui ouvre
  Synxio.
- **Mode ambiant** : lecteur à plat, sans fond ni boutons, pour l'écran toujours allumé.

### Sous le capot
- Nouveau module `:wear` (Compose for Wear OS Material 3, Tiles, Complications) et module
  `:wear-protocol` partagé. Le téléphone publie son état sur le Wearable Data Layer à chaque
  transition ; la montre extrapole la position, rien ne tourne en continu.
- Version commune téléphone/montre dans `gradle.properties`. La release GitHub publie
  désormais deux APK.

### Installation
Voir le README, section « Montre (Wear OS) » : l'APK montre se pousse par ADB Wi-Fi.
```
