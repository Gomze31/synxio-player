# Synxio 6.0 — Étape 2 : Tâches de fond fiables (WorkManager) — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Les analyses de fond (niveau sonore, empreinte 27-D, cascade de métadonnées) tournent dans des Workers Hilt : reprise après mort du processus, batterie respectée, progression visible, annulation propre.

**Architecture:** `TrackAnalysisWorker` (unique `track-analysis`) parcourt les titres sans mesure à jour et écrit `loudness` et `audio_features` au fil de l'eau ; `LoudnessRepository` et `SimilarityRepository` deviennent de minces façades : `analyseLibrary` enfile le Worker, `progress` lit `WorkInfo`. `MetadataCascadeWorker` (unique `metadata-cascade`) exécute `MetadataEnricher.runAutoPass()` ; les demandes manuelles restent en processus, sérialisées par un mutex. Les deux décodeurs existants (`LoudnessAnalyzer`, `AudioFeatureAnalyzer`) sont conservés tels quels : la passe de décodage unique arrive avec le DSP de l'étape 5.

**Tech Stack:** `androidx.work:work-runtime-ktx:2.12.0`, `androidx.hilt:hilt-work:1.4.0` + `androidx.hilt:hilt-compiler:1.4.0` (KSP), Hilt 2.60.1, Room 2.8.5, JUnit4.

**Spec:** `docs/superpowers/specs/2026-11-24-synxio-6.0-flow-design.md` §2 ; prérequis : étape 1 livrée (`v5.11.0`, plan `2026-11-24-synxio-6.0-etape-1-bibliotheque-instantanee.md`).

### Task 3 : `TrackAnalysisWorker`, scheduler, façades, réglage « en charge »

- [ ] `AudioFeatureDao` : `@Query("SELECT COUNT(*) FROM audio_features") suspend fun count(): Int`.
- [ ] `SettingsRepository` : `Settings.analyseOnlyWhenCharging: Boolean = false`, clé `ANALYSE_ONLY_CHARGING = booleanPreferencesKey("analyse_only_charging")`, lecture, `setAnalyseOnlyWhenCharging`.
- [ ] `ReplayGain.kt` : `internal object ReplayGain { suspend fun dbfs(path: String): Float? }` (corps de `LoudnessRepository.replayGainDbfs`), constantes `UNMEASURABLE_DBFS = 1f`, `REFERENCE_DBFS = -18f`.
- [ ] `TrackAnalysisScheduler` (`@Singleton`, `WorkManager.getInstance(context)`) :
  - `fun enqueue(priorityPaths: List<String> = emptyList())` : `OneTimeWorkRequestBuilder<TrackAnalysisWorker>()` + contraintes (`setRequiresBatteryNotLow(true)`, `setRequiresStorageNotLow(true)`, `setRequiresCharging(onlyWhenCharging.value)` où `onlyWhenCharging` est un `StateFlow<Boolean>` du réglage), `inputData = workDataOf(KEY_PRIORITY to priorityPaths.toTypedArray())`, `enqueueUniqueWork(NAME, ExistingWorkPolicy.KEEP, request)`.
  - `fun cancel()` : `cancelUniqueWork(NAME)`.
  - `suspend fun enqueueIfOptedIn()` : si `settings.normalizeVolume` ou `audioFeatureDao.count() > 0` → `enqueue()`.
  - `val progress: StateFlow<AnalysisRun?>` depuis `getWorkInfosForUniqueWorkFlow(NAME)` : `AnalysisRun(done, total, title, running)` lu dans `WorkInfo.progress` (clés `done`, `total`, `title`) ; `running = state == RUNNING || state == ENQUEUED || state == BLOCKED`.
- [ ] `TrackAnalysisWorker` (`@HiltWorker`, `CoroutineWorker`, `@AssistedInject`) : dépendances `LibrarySongDao`, `LibraryFiltersSource`, `LoudnessDao`, `AudioFeatureDao`, `LoudnessAnalyzer`, `AudioFeatureAnalyzer`.
  - `doWork` : titres = `LibraryBuilder.build(songDao.all().map { it.toSong() }, filters.current())` → `songs + podcasts + audiobooks` ; plan = `AnalysisPlanner.plan(...)` ; si vide → `Result.success()`.
  - Si `plan.size > 50` : `runCatching { setForeground(foregroundInfo(0, plan.size)) }` (canal `analyses`, « Analyse de la bibliothèque », importance basse, bouton Arrêter via `WorkManager.getInstance(context).createCancelPendingIntent(id)`).
  - Boucle séquentielle : `setProgress(workDataOf("done" to i, "total" to n, "title" to song.title))` ; loudness : `ReplayGain.dbfs(song.path) ?: loudnessAnalyzer.analyse(song.path) ?: UNMEASURABLE_DBFS` → `loudnessDao.put(...)` ; empreinte : `featureAnalyzer.analyse(song.path)?.let { audioFeatureDao.put(AudioFeatureEntity(path, vector, fileModifiedSec, now)) }` ; `coroutineContext.ensureActive()` à chaque tour ; toute exception par titre est journalisée et n'arrête pas la boucle.
  - Fin : `Result.success(workDataOf("done" to n, "total" to n))`. Si le Worker est arrêté, les lignes déjà écrites restent : reprise au prochain enfilage.
- [ ] `LoudnessRepository` : supprime `job`, `_progress` ; `progress = scheduler.progress.map { LoudnessProgress(it?.done ?: 0, it?.total ?: 0, it?.running == true) }.stateIn(scope, Eagerly, LoudnessProgress())` ; `analyseLibrary(songs)` → `scheduler.enqueue()` ; `cancel()` → `scheduler.cancel()` ; `clear()` → `cancel(); dao.clear()`. Même traitement pour `SimilarityRepository` avec `AnalysisProgress`.
- [ ] `MusicRepository.synchronise` : après `enricher.onLibraryScanned(cachedSongs)` → `analysisScheduler.enqueueIfOptedIn()`.
