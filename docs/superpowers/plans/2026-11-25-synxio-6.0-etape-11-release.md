# Synxio 6.0 — Étape 11 : clôture et release 6.0.0 « Flow » — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fermer la 6.0 « Flow » : brancher sur l'accueil les deux cartes laissées en attente par l'étape 10 (« Course », « Décris ta playlist »), vérifier la cohérence des écrans ajoutés depuis la 5.11.0, écrire les notes de version 6.0.0 qui récapitulent les dix étapes par pilier avec la liste consolidée des écarts et la checklist téléphone complète, mettre à jour le README et la spec, passer la version à 6.0.0 et préparer la release (tag local, poussé par la session parente).

**Architecture:** Aucun nouveau moteur. La carte « Course » n'apparaît que si l'appareil a un podomètre (`Sensor.TYPE_STEP_DETECTOR`, même test que `LibraryScreen.MoodGrid`) **et** qu'une course a déjà été lancée : cette seconde condition n'existait nulle part (`RunSession` ne vit qu'en mémoire), elle devient un booléen DataStore `run_done` dans `SettingsRepository`, hors de la classe `Settings` (pas de réglage visible, donc pas de ligne au `SettingsCatalog`), posé à `true` par `AppViewModel.startRun`. La règle d'affichage est une fonction pure `showRunCard(hasStepDetector, runDone)` dans `ui/screens/HomeFlowCards.kt`, testée en JVM. Les deux cartes sont des `FlowActionCard` (carte de verre carrée de la largeur des mosaïques, icône, titre, sous-titre) dans la `LazyRow` de la section `s-flow`, à côté de « Flow du jour » ; la section s'affiche dès qu'une des trois cartes existe. Les routes `Routes.RUN_MODE` et `Routes.NATURAL` existent déjà (étapes 8 et 9) : `SynxioRoot` les passe à `HomeScreen` comme il le fait pour `LibraryScreen`.

**Tech Stack:** Kotlin, Jetpack Compose (Material 3, icônes étendues `DirectionsRun`, `AutoAwesome`), DataStore Preferences, Hilt, JUnit4. Gradle depuis PowerShell uniquement.

**Spec:** `docs/superpowers/specs/2026-11-24-synxio-6.0-flow-design.md` §10.2 (accueil), §11 (erreurs), §12.2 (version), §12.3 (étape 11), §12.4 (checklist). Sources : plans `docs/superpowers/plans/2026-11-2*-synxio-6.0-etape-1…10-*.md` (sections « Écarts assumés »), notes `docs/release-notes/v5.11.0.md` … `v5.20.0.md`, `docs/AUDIT_EVOLUTION_2026-11.md` §6 (lots suivants).

**Écarts assumés avec la spec (étape 11) :**
- « Une course a déjà eu lieu » = une course a déjà été **lancée** depuis l'écran Course (`startRun`), pas forcément menée jusqu'à une cible : l'app ne garde aucune trace des courses (pas d'historique, pas de pas), seul ce booléen est ajouté.
- La section « Flow » montre « Décris ta playlist » même sans bibliothèque analysée : l'écran lui-même explique quand l'analyse manque (étape 9). « Flow du jour » garde sa condition (≥ 8 titres aimés analysés).
- Pas de refonte des textes des écrans Course, Décris ta playlist et Insights : seule une passe de lecture (français, tutoiement) ; aucun écart trouvé n'impose de changement de structure.
- La version passe à `6.0.0` avec `versionCode = 20261230` (jour suivant la 5.20.0), sans suffixe ; la montre partage la version sans changement de fonction.
- Le tag `v6.0.0` est posé en local seulement : le classificateur de permissions refuse `git push origin vX.Y.Z` aux sessions enfants ; la session parente ou l'utilisateur le pousse, `release.yml` publie.

Nouvelle carte, après `MosaicCard` :

```kotlin
/**
 * Carte d'action de la section « Flow » : même empreinte carrée qu'une mosaïque, verre,
 * icône en haut, titre et sous-titre en bas. Pas de pochette : elle ouvre un écran.
 */
@Composable
private fun FlowActionCard(
    icon: ImageVector,
    title: String,
    subtitle: String,
    onClickLabel: String,
    onClick: () -> Unit,
    modifier: Modifier = Modifier,
) {
    val scheme = MaterialTheme.colorScheme
    GlassCard(
        modifier = modifier
            .width(SmartCardWidth)
            .aspectRatio(1f)
            .semantics { contentDescription = onClickLabel },
        onClick = onClick,
        contentPadding = Space.md,
    ) {
        Column(Modifier.fillMaxSize()) {
            Icon(icon, contentDescription = null, tint = scheme.primary, modifier = Modifier.size(28.dp))
            Spacer(Modifier.weight(1f))
            Text(title, style = MaterialTheme.typography.titleMedium, color = scheme.onSurface, maxLines = 2, overflow = TextOverflow.Ellipsis)
            Spacer(Modifier.height(Space.xxs))
            Text(subtitle, style = MaterialTheme.typography.bodySmall, color = scheme.onSurfaceVariant, maxLines = 2, overflow = TextOverflow.Ellipsis)
        }
    }
}
```
