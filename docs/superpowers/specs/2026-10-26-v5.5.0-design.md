# Synxio Player 5.5.0 — design

## 1. Rotation de la clé de signature (lignée APK Signature Scheme v3)

- La nouvelle clé et ses mots de passe sont générés par l'utilisateur
  (`scripts/rotate-release-key.sh`) ; rien de secret ne passe par le dépôt ni par Claude.
- `apksigner rotate` produit une lignée ancienne clé → nouvelle clé. L'ancienne garde ses
  droits par défaut, sauf le retour arrière : un APK signé avec l'ancienne clé seule ne
  peut plus mettre à jour une appli déjà signée par la lignée (Android 9+).
- CI (`release.yml`) : Gradle construit l'APK (clé de secours), puis `apksigner sign
  --lineage` le re-signe : v1/v2 avec l'ancienne clé (Android 8), v3 avec la lignée.
  Secrets requis : `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`,
  `LINEAGE_BASE64`. Sans eux, la release **échoue**.
- `UpdateRepository.hasMatchingSignature` : l'APK téléchargé est accepté si son historique
  de signature (lignée) contient le certificat qui signe l'appli installée. C'est la règle
  d'Android ; après la 5.5, un APK signé par l'ancienne clé seule est refusé.

## 2. Tuile Réglages rapides

`PlaybackTileService` (`TileService`) : un `MediaController` vers `PlaybackService` le temps
de l'affichage. Toucher : lecture / pause (reprise de la file sauvegardée si rien n'est
chargé). Sous-titre : titre en cours. Appui long : ouvre l'appli (`ACTION_QS_TILE_PREFERENCES`).

## 3. Enregistrer la file en playlist

Menu du lecteur : « Enregistrer la file » ; boîte de dialogue avec un nom proposé
(« File du 26/10 ») ; `PlaylistRepository.create(name, queue)` ; message de confirmation.

## 4. Vitesse par émission

- Table `show_speeds(showKey, speed)`. Clé d'émission : `podcast:<album>` pour un podcast,
  `book:<dossier>` pour un livre audio (`ShowKeys.of(song)`, testé).
- Au changement de titre : émission avec vitesse mémorisée → cette vitesse ; sinon vitesse
  globale. Changer la vitesse pendant un podcast / livre audio l'enregistre pour l'émission
  au lieu du réglage global.

## 5. Notes étoiles

- Table `song_ratings(songId, stars, updatedAt)` ; 0 = pas de note (ligne supprimée).
- Lecteur : rangée de 5 étoiles sous le titre (toucher la note actuelle l'efface).
  Éditeur de tags : même rangée.
- Playlists à règles : champ `RATING` (« Note »), opérateurs numériques.
- Sauvegarde / restauration : notes incluses (champ optionnel, anciennes sauvegardes OK).
- Pas d'écriture dans les fichiers (formats hétérogènes, autorisation par fichier).

## Base de données

v14 → v15 : `song_ratings`, `show_speeds`.
